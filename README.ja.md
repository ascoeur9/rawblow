**RAW 写真を高速にめくって選び抜くセレクトビューア。** Rust + egui/wgpu ネイティブ · Windows / macOS / Linux

数千枚の RAW を素早くめくりながら採用・保留・除外に分類し、選んだ写真だけをコピー・移動する軽量なセレクトツールです。普段は RAW に含まれる埋め込みプレビューをそのまま表示するのでめくりが速く、ピントやディテールを精密に確認するときだけフル解像度を読み込みます。分類結果はフォルダ内のサイドカーファイルにのみ記録し、オリジナルには一切手を加えません。

上の段落は AI が書いた説明文で、RawBlow は実のところ、Lightroom に RAW を放り込んでセレクトしていたら遅すぎて頭に来て、抑えきれずに机を殴ろうとしたらエイムをミスして自分の急所を叩いてしまい、その痛みに耐えかねて作った爆速 RAW ビューア / セレクトツールです…

セレクトを楽に速くする機能を足し続けていますが、何よりもまず「速いセレクト」を最優先にしています。

---

## 基本の流れ

1. フォルダを開きます。左上の **フォルダを開く** ボタン、`⌘/Ctrl+O`、ウィンドウへのドラッグ＆ドロップのうち好きな方法でどうぞ。
2. `←` `→` でめくりながら `Q`（採用）`W`（保留）`E`（除外）を押します。星評価 `1`～`5` とカラータグ `⇧1`～`⇧5` はラベルとは別の軸なので、同時に付けられます。
3. 左レールで見たい組み合わせだけに絞り込んだら、`Enter` で転送画面を開き、選んだファイルだけをコピーまたは移動します。

作業中もオリジナルファイルはそのままです。ラベル・星評価・タグはフォルダ内の `.rawblow/session.json` にだけ溜まり、フォルダを開き直せばそのまま復元されます。

## 主な機能

### 表示とめくり

- **シングルビューとグリッド。** 下部にフィルムストリップが付いたシングルビューと、サムネイルグリッドを `T` で切り替えます。グリッドの列数は設定で 4～12 の間で決めます。
- **拡大。** 写真をクリックするとウィンドウフィットと 1:1 を行き来します。`Ctrl`+ホイールやタッチパッドのピンチで連続ズームし、拡大した状態ではドラッグで移動します。倍率は右下に表示され、100% がオリジナル 1 ピクセル対画面 1 ピクセルです。写真をめくっても拡大状態は保たれます。
- **原寸表示（ORIG）。** 埋め込みプレビューの代わりに RAW をフル解像度でデコードし、実際のディテールを確認します。`D` またはツールバーの **ORIG** ボタンで切り替え、ファイルによっては読み込みに少し時間がかかります。めくるときに原寸表示を維持するかどうかは設定で選べます。
- **オーバーレイ。** `I` で EXIF、`H` で RGB ヒストグラム、`A` でカメラが合わせた AF 測距点、`M` で GPS が記録された写真の撮影地ミニマップを表示します。
- **写真の背景色。** 表示画面の背景をプリセット（黒、グレー 3 段階、白）または HEX・RGB の直接入力で変更します。Lightroom の現像モジュール既定値である 50% グレーもプリセットにあります。
- **全画面。** `F11` またはツールバーの **Full** ボタン。シングルでもグリッドでも、全画面中にめくり・拡大・原寸表示のショートカットがそのまま効きます。
- 縦横の自動回転、RAW+JPG ペアリング、RAW+ バッジに対応しています。

### 分類

- **ラベル。** `Q` 採用、`W` 保留、`E` 除外、`R` 解除。同じキーをもう一度押すと外れます。ラベルを付けると自動的に次の写真へ進み、設定でオフにできます。
- **星評価。** `1`～`5` で付け、`` ` ``（バッククォート）で解除します。ラベルとは独立した軸なので同時に付きます。
- **カラータグ。** `⇧1`～`⇧5` でオレンジ・ピンク・ティール・青・紫を付け、`⇧0` で外します。ラベル・星評価とは独立です。設定で色ごとに名前を付ければ（補正方式など）、その名前がフィルタ・転送・ファイル名まで引き継がれます。
- **グリッドの複数選択。** `Ctrl`（`⌘`）+クリックで 1 枚ずつトグルし、クリックしてから `Shift`+クリックで範囲を選びます。選んだ分をまとめて `Q` `W` `E` `R` や星評価で分類します。
- **一括ラベル。** グリッドで `B`。ファイル名やその一部を改行・カンマ・タブで区切って貼り付けると、一致した項目にまとめてラベルを付けます。
- **元に戻す。** `⌘/Ctrl+Z` で元に戻し、`⌘/Ctrl+⇧Z` または `⌘/Ctrl+Y` でやり直します。
- **非破壊保存。** ラベル・星評価・カラータグはフォルダ内の `.rawblow/session.json` に保存され、人が読める txt も一緒に出力されます。オリジナルファイルには触れません。

### 絞り込み

- **フィルタ。** 左レールでラベル、星評価（ちょうど N 点）、カラータグをそれぞれ選びます。3 つは互いに独立で、AND で重ねて掛かります。ラベルフィルタだけを切り替えるなら `F`。
- **ジャンプ。** `G` で番号かファイル名の一部を入力すると、その場所へ一度に移動します。
- **フォルダごとの再開。** フォルダごとに最後に見ていた写真を覚えていて、開き直すとその位置から始まります。並び順ではなくファイルパスを覚えるので、ファイルを足しても消しても、並び順を変えても同じ写真に戻ります。
- **並び順。** 既定は撮影日時順で、設定でファイル名順に変えられます。複数のカメラを混ぜて使うと、ファイル名が撮影順と食い違うためです。

### AIカリング（テスト中）

> **モデルが判定する項目はまだテスト中です。** 顔検出・AI シャープネス・オブジェクト検出などの判定には誤りがあり得るので、結果を鵜呑みにしないでください。オリジナルファイルが削除されることはなく、落選したカットもラベル・星評価・タグの値が変わるだけです。

写真を解析して良い・落選を自動で振り分けます。結果は指定した 1 つの軸（ラベル・星評価・カラータグのいずれか）にだけ入るので、手で付けた軸には触れません。解析はすべてこのパソコンの中で、バックグラウンドで走り、途中でキャンセルできます。

- **モデル不要の判定。** フォーカス（シャープネス）、露出、水平の傾き。フォーカスはフレーム全体ではなく、カメラが合わせた AF 測距点の範囲だけで測ることもできます。
- **メタデータフィルタ。** 縦横、ISO 上限、焦点距離の範囲、絞り上限、シャッター速度下限、カメラ名・レンズ名の部分一致。
- **連写ベスト N。** 指定した間隔の中で撮られたカットを 1 グループとみなし、その中でスコア上位 N 枚だけを残します。
- **重複整理。** ほぼ同じ場面をパーセプチュアルハッシュでまとめ、クラスタごとにベストだけを残します。
- **モデルが必要な判定。** 美的スコア（CLIP-IQA）、AI シャープネス、ジャンルピック（人物 / 風景）、顔検出（YuNet）、オブジェクト検出（YOLOv10n）。モデルは初回使用時に自動でダウンロードし、sha256 で検証します。
- **GPU 高速化。** Windows は WebGPU、macOS は CoreML を使います。登録に失敗した場合は静かに CPU にフォールバックします。

### 書き出し

- **転送。** 選んだファイルだけをコピーまたは移動します。ラベル・星評価・カラータグで対象を決め、3 つのうちどれか 1 つでも該当すれば対象になります（和集合）。ラベル・タグ別のサブフォルダへの振り分け、付随ファイルの扱い、名前が衝突したときの連番を選べます。移動を使うと、移動された項目はリストから自動的に外れます。進捗バーとキャンセルボタンがあるので、大きなフォルダや遅いドライブでも固まったようには見えません。
- **転送時のリネーム。** 連番（1, 2, 3）、評価ランク（A1, B1 …）、自作テンプレートから選びます。テンプレートには `{seq}` `{gradeseq}` `{grade}` `{stars}` `{label}` `{tag}` `{orig}` が使え、`{seq:03}` のようにゼロ埋めもできます。プレビューがリアルタイムに出て、RAW+JPG ペアは同じ名前になります。
- **フォルダ整理。** 左レール下部の **整理** ボタンで、フォルダ内の写真を撮影日・カメラ・レンズ・焦点距離・拡張子を基準にサブフォルダへ振り分けます（移動またはコピー）。EXIF 基準では RAW+JPG ペアを同じフォルダに保ち、EXIF を読めないファイルは `unknown-date` のようなフォルダにまとまります。整理したフォルダはそのまま開いてセレクトでき、転送とは別の機能です。

### そのほか

- **高速ローディング。** 埋め込みプレビューを画面サイズに合わせて縮小デコードし、バックグラウンドデコード・先読みプリロード・LRU テクスチャキャッシュを併用します。
- **サムネイルディスクキャッシュ。** 一度デコードしたサムネイルは OS キャッシュに残るので、フォルダを閉じて開き直しても再デコードなしで表示されます。設定で使用量の確認とクリアができ、上限（既定 1GB、0 で無制限）を超えると古いものから削除されます。
- **多言語。** 한국어 / English / 日本語。OS の言語に従い、設定で変えると保存されます。
- **ショートカット一覧。** `?` または `F1` でアプリ内から全ショートカットを確認できます。
- **アップデート通知。** 起動後アイドル時に GitHub の最新リリースを確認し、新しいバージョンがあれば左レールに通知ボタンを表示します。設定でオフにできます。
- **オープンソースライセンス表示。** 設定画面で同梱コンポーネントの一覧とライセンス全文を確認できます。

## インストール

### Windows（Microsoft Store 推奨）

[**Microsoft Store で入手**](https://apps.microsoft.com/store/detail/9PC2FKGPQPD1)。ストアからインストールすると自動的に更新され、セキュリティ警告なしにすぐ起動します。

Microsoft Store を利用できない場合にかぎり、[**Releases**](https://github.com/ascoeur9/rawblow/releases/latest) から `RawBlow-Setup-vX.Y.Z.exe` をダウンロードしてください。必要なランタイムはすべて同梱されているので、別途インストールするものはありません。コード署名がないため、初回起動時に SmartScreen の「Windows によって PC が保護されました」が出たら **詳細情報 → 実行** を押してください。

### macOS（Apple Silicon）

[**Releases**](https://github.com/ascoeur9/rawblow/releases/latest) から `RawBlow-vX.Y.Z-macos-arm64.zip` をダウンロードし、解凍すると `RawBlow.app` が出てきます。

公証（notarize）を受けていないため、初回起動時に「開発元を確認できません」という警告が出ます。ダイアログで **完了** を押し、**システム設定 → プライバシーとセキュリティ → セキュリティ** の下部にある **このまま開く** を押してください。macOS 15 Sequoia 以降、従来の右クリック → 開くによる回避はもう動きません。ターミナルを使うなら次の 1 行でも同じです。

```bash
xattr -dr com.apple.quarantine /Applications/RawBlow.app
```

### ソースからビルド（Linux、その他）

```bash
cargo build --release -p rawblow-app   # 実行物: target/release/rawblow(.exe)
cargo run   --release -p rawblow-app
```

Rust 1.80 以降と C リンカ（MSVC Build Tools / gcc / clang）が必要で、Linux では Vulkan ランタイムも要ります。日本語フォントは OS のフォントから自動的に読み込まれます。

配布用のクリーンリリースビルド（単独実行 + ビルドパス・ユーザー名の除去）については [`BUILD.md`](BUILD.md) を参照してください。

## 対応フォーマットと確認済みカメラ

RAW は `.ARW` `.CR2` `.CR3` `.NEF` `.ORF` `.RW2` `.RAF` `.DNG` `.PEF` `.SRW` `.RAW`、通常の画像は `.JPG` `.JPEG` `.PNG` `.WEBP` `.HEIC` `.HEIF` `.TIF` `.TIFF` を読み込みます。

**OS。** Windows 11 と macOS（Apple Silicon）向けに正式配布しています。Linux はコード上サポートしていますが、ビルド済みバイナリは提供していないのでソースからビルドしてください。

下の一覧にないボディも動くように作っていますが、検証していないボディは埋め込みプレビュー経路で表示されます。新しいボディでグレー画面や表示崩れ、エラーが出たら、ぜひお知らせください。

バグ（特に強制終了）、表示エラー、新しいカメラのサポート要望は、お好きな方へどうぞ。

- **GitHub Issues** [github.com/ascoeur9/rawblow/issues](https://github.com/ascoeur9/rawblow/issues)

強制終了が起きると、デスクトップに `rawblow_crash.log` が自動生成されます。このファイルを添付するか、内容を貼り付けてください。次の情報も一緒に書いていただけると原因を特定しやすくなります。

- カメラボディとファイルフォーマット、おおよその枚数
- OS と GPU（可能であれば）

## 既知の制限

- カラーマネジメントは埋め込み ICC から sRGB までです。モニターの ICC プロファイルは参照せず、sRGB を想定しています。
- ショートカットを再割り当てする画面はありません。デフォルト固定です。
- HEIC など一部のフォーマットはプラットフォームのデコーダに依存します。
- 原寸表示は GPU テクスチャの上限（長辺およそ 8192px）の範囲内で表示します。
- ペンタックスはファイルのどこにもレンズ名が記録されていないため、レンズ欄が空になります。
- AIカリングのうちモデルが判定する項目はテスト段階です。
