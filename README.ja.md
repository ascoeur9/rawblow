**高速 RAW 写真カリング（セレクト）ビューア** — Rust + egui/wgpu ネイティブ · Windows / macOS / Linux

数千枚の RAW を素早くめくりながら **採用 / 保留 / 除外** に分類し、選んだ写真だけをコピー・移動する軽量なセレクトツールです。RAW に含まれる埋め込みプレビューをそのまま表示するためめくりが速く、ピント・ディテールを精密に確認したいときだけ **ORIG（オリジナル）** でフル解像度を読み込みます。分類結果はオリジナルに手を加えず、サイドカーファイルにのみ記録します（非破壊）。

---

## 主な機能

- **2つの表示** — シングルビュー（+下部フィルムストリップ）/ サムネイルグリッド（T で切り替え）
- **分類** — Q 採用 · W 保留 · E 除外 · R 解除、自動前進、ラベル別フィルタ
- **星評価（★1～5）** — 数字 **1～5** で星評価、**`（バッククォート）** で解除。ラベル（QWER）とは **独立** して同時に付けられ、転送時に星評価を基準に選ぶこともできます
- **カラータグ** — **⇧1～5** で 5 色タグ（オレンジ・ピンク・ターコイズ・ブルー・パープル）をラベル・星評価とは **独立** して付与。設定で色ごとの名前を指定（例：補正方式）でき、フィルタ・転送・ファイル名に反映されます
- **表示フィルタ** — 左側のレールで **ラベル**・**星評価（ちょうど N 点）**・**カラータグ** を **独立に AND** 組み合わせて、目的のカットだけを絞り込んで表示
- **グリッド複数選択** — Ctrl（⌘）+クリックでトグル、クリック後 Shift+クリックで範囲選択 → Q/W/E/R・星評価で **まとめて** 分類
- **AIカリング** — 写真を解析して **ブレ（ピント）・露出・水平の傾き**、オプションで **美的スコア（CLIP-IQA AI）** で自動分類。良/除外を **ラベル・星評価・カラータグ** のいずれかに割り当て（手動の分類軸はそのまま）。すべて **ローカル処理** + **GPU 高速化**（Windows WebGPU / macOS CoreML）、バックグラウンドで非ブロッキング実行。モデルは初回使用時に自動ダウンロード（sha256 検証）
- **拡大/移動** — 写真をクリックでウィンドウフィット↔1:1、**Ctrl+ホイールまたはタッチパッドのピンチ** で連続拡大、拡大状態で **ドラッグして移動**。倍率は右下に表示
- **ORIG（オリジナル表示）** — RAW をフル解像度でデコードして実際のディテールを確認（読み込みに少し時間がかかる場合があります）。必要なときだけ手動で使用
- **EXIF オーバーレイ（I）** · **RGB ヒストグラム（H）**
- **写真の背景色** — 表示画面の背景を設定で変更（プリセット：黒・グレー・白、Lightroom 基準の 50% グレーなど / **HEX・RGB 直接入力**）
- **縦/横の自動回転**、RAW+JPG ペアリング、RAW+ バッジ
- **転送（Transfer）** — 選んだファイルだけをコピー/**移動**（ラベル・**星評価**・**カラータグ** 基準、ラベル/タグ別フォルダ、付随ファイル、衝突時は連番）。**移動（Move）** 時、移動された項目はリストから自動整理されます。転送中は **進捗バー・キャンセル** を表示 — 大きなフォルダや遅いドライブでも固まったように見えません
- **転送時のファイル名変更** — 連番（1,2,3）/ **星評価グレード（A1,B1…）** / 自作テンプレート（`{seq}` `{gradeseq}` `{stars}` `{tag}` `{orig}` など）でコピー・移動しながらリネーム（ライブプレビュー、RAW+JPG ペアは同一名）
- **フォルダ自動整理** — 左レール下部の **整理** ボタンで、フォルダ内の写真を **撮影日 / カメラ / レンズ / 拡張子** 基準でサブフォルダに振り分け（移動またはコピー）。EXIF 基準では RAW+JPG ペアを同じフォルダに保ち、整理後は結果をすぐに開いてセレクトできます（転送とは別機能）
- **アップデート通知** — 起動後アイドル時に GitHub の最新リリースを確認し、新しいバージョンがあれば整理ボタンの上に通知ボタンを表示（クリックで Releases を開く）
- **多言語** — 한국어 / English / 日本語（OS 言語を自動検出、設定で変更・保存）
- **フルスクリーン** — **F11** またはツールバーボタンで OS ウィンドウのフルスクリーン。シングル/グリッドのどこからでも、フルスクリーン中でもめくり・ORIG・拡大のショートカットが動作
- **非破壊保存** — フォルダ内の `.rawblow/session.json`（+人が読める txt）に分類・星評価・カラータグを保存・復元
- **高速ローディング** — バックグラウンドデコード + 先読みプリロード + LRU テクスチャキャッシュ
- **サムネイルディスクキャッシュ** — 一度デコードしたサムネイルを OS キャッシュに保管 → フォルダを閉じて再び開いても **再デコードなしで即時表示**。設定で容量確認・クリア + **自動上限（MB、ユーザー指定・デフォルト 1GB）** を超えると古いものから自動整理

## インストール / 実行

### ダウンロードしてすぐ実行
[**Releases**](https://github.com/ascoeur9/rawblow/releases/latest) から OS に合ったファイルをダウンロードしてください。

- **Windows x64** — `RawBlow-Setup-vX.Y.Z.exe` を実行してインストール（必要なランタイムをすべて同梱）。署名がないため、初回起動時に SmartScreen の「Windows によって PC が保護されました」警告が出たら **詳細情報 → 実行** をクリック。
- **macOS (Apple Silicon)** — `RawBlow-vX.Y.Z-macos-arm64.zip`（解凍すると `RawBlow.app`）
  - 初回起動時に「開発元を確認できません」という警告が表示されたら（公証なし）：ダイアログで **完了** を押し、**システム設定 → プライバシーとセキュリティ → セキュリティ** セクション下部の **このまま開く** を押してください。（macOS 15 Sequoia 以降、従来の **右クリック → 開く** による回避は動作しません。）
  - または、ターミナルで `xattr -dr com.apple.quarantine /Applications/RawBlow.app`

### ソースからビルド（Linux、その他）
```bash
cargo build --release -p rawblow-app   # 実行物: target/release/rawblow(.exe)
cargo run   --release -p rawblow-app
```
要件：Rust 1.80+、C リンカ（MSVC Build Tools / gcc / clang）、Linux は Vulkan ランタイム。日本語フォントは OS のフォントから自動的に読み込まれます。

> 📌 **配布用クリーンリリースビルド**（単独実行 + ビルドパス/ユーザー名の除去）については [`BUILD.md`](BUILD.md) を参照してください。

## 使い方

| 動作 | キー / 操作 |
|------|-----------|
| フォルダを開く | 左上の **フォルダを開く** ボタン · ⌘/Ctrl+O |
| 前/次の写真 | ← / → |
| グリッドで上/下の行 | ↑ / ↓（選択に合わせて自動スクロール） |
| 採用 / 保留 / 除外 / 解除 | **Q** / **W** / **E** / **R** |
| 星評価の指定 / 解除 | **1 2 3 4 5** / **`**（バッククォート）— ラベルと独立 |
| カラータグの指定 / 解除 | **⇧1 ～ ⇧5** / **⇧0** — ラベル・星評価と独立 |
| シングルビュー ↔ グリッド | **T** |
| ウィンドウフィット ↔ 1:1 | 写真を **クリック** · Space · Z |
| 拡大 / 縮小 | **Ctrl+マウスホイール** · タッチパッド **ピンチ** |
| 拡大状態で移動 | 写真を **ドラッグ** |
| オリジナル表示（ORIG） | **D** · ツールバー **ORIG** |
| EXIF / ヒストグラム | **I** / **H** |
| フルスクリーン | **F11** · ツールバー **Full**（ESC/F11 で解除） |
| ジャンプ（番号で移動） | **G** |
| フィルタ切り替え | **F** |
| 転送（選択ファイルをコピー/移動） | **Enter** · ⌘/Ctrl+E |
| グリッド複数選択 | **Ctrl/⌘+クリック**（トグル） · クリック後 **Shift+クリック**（範囲） |

- **OS**: Windows 11 · macOS (Apple Silicon) を正式に配布しています。Linux はコード上サポートしていますが、ビルド済みバイナリは提供していません（ソースビルド）。

## 既知の制限

- カラーマネジメントは埋め込み ICC → sRGB まで（モニター ICC プロファイルの参照は未対応、sRGB を想定）。
- ショートカット再バインドの UI なし（デフォルト値で固定）。
- HEIC など一部のフォーマットはプラットフォームのデコーダに依存。
- ORIG オリジナル表示は GPU テクスチャの上限（約 8192px）の範囲内で表示します。
