## RawBlow v0.7.0

> **다운로드** — Windows(x64): [**Microsoft Store**](https://apps.microsoft.com/store/detail/9PC2FKGPQPD1) 에서 설치하세요(자동 업데이트·보안 경고 없음).
> Microsoft Store를 이용할 수 없는 경우에만 아래 `RawBlow-Setup-v0.7.0.exe` 설치 파일을 받으세요.
> macOS(Apple Silicon): 아래 `RawBlow-v0.7.0-macos-arm64.zip` 을 받으세요.

### ⚠️ AI 컬링은 테스트 중인 기능입니다
얼굴 검출 · AI 선명도 · 객체 포함 등 ONNX 기반 판정은 **아직 테스트 중이라 오류가 있을 수 있습니다.** 결과를 맹신하지 마세요. 원본 파일은 삭제되지 않으며, 걸러진 컷은 숨김/표시로만 처리됩니다.

### 룩과 LUT (#125)
단일 보기와 전체화면에서 사진에 색 보정을 씌워 볼 수 있습니다. 툴바의 **LUT** 버튼을 누르면 내장 룩 6종(Rawblow-Warm · Rawblow-Tungsten · Rawblow-Chrome · Rawblow-Pan · Rawblow-Vivid · Rawblow-Snap)과 LUT 폴더의 `.cube` 파일이 나옵니다. LUT 폴더는 설정의 **LUT 폴더**에서 고릅니다.
- `\`를 누르고 있는 동안 룩을 끄고 원래 색과 비교합니다.
- 보기에만 적용합니다. 원본 파일과 전송한 파일은 바뀌지 않고, 히스토그램도 룩을 씌우기 전 값을 보여줍니다.
- 읽을 수 없는 `.cube`를 고르면 알림을 띄우고 이전 룩을 그대로 둡니다.

### 구도 보조선 (#90)
단일 보기 툴바의 **구도** 버튼이나 `]` 키로 삼분할 · 중앙 십자 · 정방형 · 사용자 지정 보조선을 차례로 켭니다. 사용자 지정은 설정에서 세로·가로 선을 8개까지 두고 색·굵기·불투명도를 바꿀 수 있습니다. 보조선은 화면에만 그려지고 전송한 파일에는 들어가지 않습니다.

### 광색역 표시 (#122)
설정에서 **광색역 표시**를 켜면 Display P3·Adobe RGB 사진을 모니터 색 공간에 맞춰 보여줍니다. 맥은 Display P3, 윈도우는 모니터에 지정한 색 프로파일(ICC)을 씁니다. 기본값은 꺼짐입니다. 오른쪽 아래 상태 바에 지금 출력 색 공간이 나옵니다.

### 시그마 X3F (#126)
시그마 X3F 파일을 RAW로 읽어 목록에 보여줍니다. 파일 안에 든 JPEG 미리보기로 표시하며, RAW 현상은 하지 않습니다.

### AI 컬링 (#124)
연사 그룹에서 베스트 컷을 고를 때 미적 점수가 있는 컷을 선명도만 있는 컷보다 앞에 둡니다.

### 그 밖에
- 툴바가 좁아지면 단축키 표시를 툴팁으로 옮기고 버튼 이름을 줄여 한 줄에 맞춥니다.
- 단일 보기의 보기 모드와 출력 색 공간(예: `FIT · sRGB`)을 상태 바에 표시합니다.
