## RawBlow v0.6.1

> **다운로드** — Windows(x64): [**Microsoft Store**](https://apps.microsoft.com/store/detail/9PC2FKGPQPD1) 에서 설치하세요(자동 업데이트·보안 경고 없음).
> Microsoft Store를 이용할 수 없는 경우에만 아래 `RawBlow-Setup-v0.6.1.exe` 설치 파일을 받으세요.
> macOS(Apple Silicon): 아래 `RawBlow-v0.6.1-macos-arm64.zip` 을 받으세요.

### ⚠️ AI 컬링은 테스트 중인 기능입니다
얼굴 검출 · AI 선명도 · 객체 포함 등 ONNX 기반 판정은 **아직 테스트 중이라 오류가 있을 수 있습니다.** 결과를 맹신하지 마세요. 원본 파일은 삭제되지 않으며, 걸러진 컷은 숨김/표시로만 처리됩니다.

### HEIC/HEIF 지원 (#97)
아이폰 HEIC를 **실제로 엽니다.** 순수 Rust 디코더(heif-oxide)를 내장해 그리드·단일·원본 보기 모두 동작합니다.

- RAW + HEIC + JPG 는 한 장으로 묶입니다. 전송·정리에서 HEIC는 JPG와 같은 「이미지」로 취급됩니다.
- `RAW/`·`JPG/`·`HEIC/` 처럼 나뉜 형제 폴더도 한 목록으로 합쳐집니다.
- HEIC 디코드에 실패하면 같은 이름의 RAW로 한 번 다시 시도합니다.

### 전송 폴더 기본값 (#113 #115 #89)
설정에 **「전송 폴더 기본값」**이 생겼습니다 — **지금 열린 폴더** 또는 **지정한 폴더**. `Ctrl+E`에서 폴더를 바꿔도 다음 전송은 다시 이 기본값으로 시작합니다.

- 한 폴더로 보내는 모드에서는 지금 열린 폴더 자체를 목적지로 쓸 수 없습니다(원본과 섞이는 사고 방지). 이때 기본값은 `{원본}/selected` 이고, 찾아보기에서 원본을 고르면 오류로 막습니다.
- 폴더 나누기는 **한 축만** 고릅니다: 한 폴더 / 라벨(QWER) / 별점 / 색 태그. 라벨로 나누면 제외 컷은 `reject` 폴더로 갑니다.

### 데이터 안전
- **사이드카 `.bak` 복구 후 `session.json` 재기록 (#96)** — 복구했는데 다시 열면 분류가 사라지던 문제 수정.
- **하위 폴더 포함 스캔의 같은 번호 구분 (#98 #107)** — 다른 폴더의 같은 파일번호가 사이드카에서 서로 덮어쓰거나 RAW+JPG로 잘못 묶이지 않습니다.
- **전송·정리 이름 충돌을 페어 단위로 회피 (#103)** — RAW와 JPG가 서로 다른 이름으로 갈라지지 않습니다.
- **일괄 분류도 되돌리기(Ctrl+Z) 대상 (#108)**.
- **원본 보기(ORIG) 정직성 (#109)** — 풀 RAW 디코드에 실패해 프리뷰로 대체되면 원본 성공으로 표시하지 않고 안내합니다.

### 조작 가드·안정성
- 원본 이동 확인창이 Enter 키 반복으로 건너뛰어지지 않습니다 (#95).
- 파일명 점프와 F키 필터가 **보이는 목록**에만 맞춰 동작합니다 — 안 보이는 사진이 분류되거나 점프가 헛도는 일이 없습니다 (#99 #102).
- 손상 파일을 백그라운드 프리페치가 무한 재시도하지 않습니다 (#100).
- 얼굴·객체 검출이 **실패**한 경우를 「없음」으로 저장하지 않아 AI 컬링이 잘못 탈락시키지 않습니다 (#101).
- 폴더를 바꾸면 이전 폴더의 EXIF 읽기가 새 폴더 메타를 막지 않습니다 (#105).
- 폴더 스캔이 백그라운드에서 돌아 NAS·하위 폴더 포함 시 앱이 멈추지 않습니다 (#116).

### 성능·기타
- 큰 그리드에서 텍스처 캐시 관리가 O(1)이 되어 CPU 사용이 줄었습니다 (#117).
- GPS 지도 타일 캐시에 용량 상한을 두었습니다 (#112).
- AI 컬링 디스크 캐시가 5만 건을 넘으면 최근 결과부터 남깁니다 (#111).
- macOS에서 한글 폴더·파일명이 자모가 분리되어 보이던 문제 수정 (#94).
