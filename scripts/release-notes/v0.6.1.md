## RawBlow v0.6.1

> **다운로드** — Windows(x64): [**Microsoft Store**](https://apps.microsoft.com/store/detail/9PC2FKGPQPD1) 에서 설치하세요(자동 업데이트·보안 경고 없음).
> Microsoft Store를 이용할 수 없는 경우에만 아래 `RawBlow-Setup-v0.6.1.exe` 설치 파일을 받으세요.
> macOS(Apple Silicon): 아래 `RawBlow-v0.6.1-macos-arm64.zip` 을 받으세요.

### ⚠️ AI 컬링은 테스트 중인 기능입니다
얼굴 검출 · AI 선명도 · 객체 포함 등 ONNX 기반 판정은 **아직 테스트 중이라 오류가 있을 수 있습니다.** 결과를 맹신하지 마세요. 원본 파일은 삭제되지 않으며, 걸러진 컷은 숨김/표시로만 처리됩니다.

### HEIC 지원 (#97)
HEIC/HEIF 파일을 열 수 있습니다. 그리드, 단일 보기, 원본 보기 모두 다른 형식과 똑같이 동작합니다.

- RAW, HEIC, JPG가 같은 이름이면 한 장으로 묶여 함께 분류됩니다. 전송과 정리에서 HEIC는 JPG와 같은 이미지 파일로 다룹니다.
- `RAW`, `JPG`, `HEIC` 폴더로 나뉘어 있어도 한 목록으로 합쳐서 보여줍니다.

### 전송 폴더 기본값 (#113 #115 #89)
설정에서 전송 폴더의 기본값을 **지금 열린 폴더**와 **직접 지정한 폴더** 중에 고를 수 있습니다. 전송 창(`Ctrl+E`)에서 폴더를 바꾸더라도 다음 전송은 다시 기본값에서 시작합니다.

- 한 폴더로 모아서 보낼 때는 지금 열린 폴더를 목적지로 지정할 수 없습니다. 원본과 전송본이 한 폴더에 섞이는 일을 막기 위해서입니다. 이 경우 기본값은 원본 폴더 아래 `selected`입니다.
- 폴더를 나누는 기준은 하나만 고릅니다. 한 폴더로 모으기, 라벨(QWER), 별점, 색 태그 중 하나입니다. 라벨로 나누면 제외한 사진은 `reject` 폴더로 갑니다.

### 분류 데이터가 더 안전해졌습니다
- 사이드카를 백업에서 복구한 뒤 다시 열면 분류가 사라지던 문제를 고쳤습니다 (#96).
- 하위 폴더까지 함께 열었을 때, 다른 폴더에 있는 같은 번호의 사진이 서로 분류를 덮어쓰거나 RAW+JPG 한 쌍으로 잘못 묶이지 않습니다 (#98 #107).
- 전송이나 정리 중 이름이 겹쳐 번호를 붙일 때, RAW와 JPG가 서로 다른 이름이 되지 않습니다 (#103).
- 여러 장을 한 번에 분류한 것도 `Ctrl+Z`로 되돌릴 수 있습니다 (#108).
- 원본 보기에서 원본 해상도를 열지 못해 미리보기로 대신 보여주는 경우, 이를 안내합니다 (#109).

### 실수를 막는 장치
- 원본을 이동하기 전 확인 창이 Enter 키를 길게 누르고 있어도 넘어가지 않습니다 (#95).
- 파일명으로 이동하거나 필터를 바꿀 때, 화면에 보이지 않는 사진이 분류되거나 선택되는 일이 없습니다 (#99 #102).
- 얼굴이나 사물을 찾지 못한 것과 검출 자체가 실패한 것을 구분합니다. 검출이 실패한 사진을 AI 컬링이 잘못 걸러내지 않습니다 (#101).

### 더 가볍게
- 폴더를 여는 동안 화면이 멈추지 않습니다. 사진이 많거나 하위 폴더가 깊어도 바로 반응합니다 (#116).
- 폴더를 바꾸면 이전 폴더의 정보 읽기를 기다리지 않고 새 폴더를 바로 보여줍니다 (#105).
- 열 수 없는 파일을 반복해서 다시 읽으려 하지 않습니다 (#100).
- 큰 그리드에서 CPU 사용이 줄었습니다 (#117).
- 지도 타일 캐시와 AI 컬링 캐시에 상한을 두어 디스크를 무한정 차지하지 않습니다 (#111 #112).
- macOS에서 한글 폴더와 파일 이름이 자모가 분리되어 보이던 문제를 고쳤습니다 (#94).

<!-- @changelog -->
- **HEIC 지원 (#97)** — HEIC/HEIF를 열 수 있고, RAW·HEIC·JPG를 한 장으로 묶습니다.
- **전송 폴더 기본값 (#113 #115 #89)** — 지금 열린 폴더 또는 지정한 폴더를 기본값으로 고릅니다. 원본 폴더로 직접 전송하는 일을 막고, 폴더 나누기 기준은 하나만 고릅니다.
- **분류 데이터 안전 (#96 #98 #103 #107 #108 #109)** — 사이드카 복구, 하위 폴더의 같은 번호, RAW+JPG 이름 쌍, 일괄 분류 되돌리기, 원본 보기 안내.
- **실수 방지 (#95 #99 #101 #102)** — 확인 창 Enter 가드, 보이는 사진만 분류, 검출 실패 구분.
- **가볍게 (#94 #100 #105 #111 #112 #116 #117)** — 폴더 열기와 전환이 멈추지 않고, 캐시에 상한을 두고, macOS 한글 표시를 고쳤습니다.
