## RawBlow v0.7.1

> **다운로드** — Windows(x64): [**Microsoft Store**](https://apps.microsoft.com/store/detail/9PC2FKGPQPD1) 에서 설치하세요(자동 업데이트·보안 경고 없음).
> Microsoft Store를 이용할 수 없는 경우에만 아래 `RawBlow-Setup-v0.7.1.exe` 설치 파일을 받으세요.
> macOS(Apple Silicon): 아래 `RawBlow-v0.7.1-macos-arm64.zip` 을 받으세요.

### ⚠️ AI 컬링은 테스트 중인 기능입니다
얼굴 검출 · AI 선명도 · 객체 포함 등 ONNX 기반 판정은 **아직 테스트 중이라 오류가 있을 수 있습니다.** 결과를 맹신하지 마세요. 원본 파일은 삭제되지 않으며, 걸러진 컷은 숨김/표시로만 처리됩니다.

### 단축키 변경 (#123)
설정 화면에 **단축키** 섹션이 생겼습니다. 동작 행의 **바꾸기**를 누른 뒤 원하는 키를 누르면 바로 지정됩니다. **QWER** · **JKL**(채택 `J` · 보류 `K` · 제외 `L` · 해제 `U`) 프리셋과 **단축키 초기화**도 함께 제공합니다.
- 이미 다른 동작이 쓰는 키를 지정하면 두 동작의 키를 맞바꾸고, 바꾼 행 바로 아래에 어느 동작의 키가 바뀌었는지 한 줄로 알립니다. 키가 없던 동작에 기존 키를 주면 원래 동작은 **없음**이 되며, 한 키에 동작이 둘 붙는 상태는 생기지 않습니다.
- 전에는 고정이던 구도선(`]`), 일괄 분류(`B`), 폴더 열기(`Ctrl+O` / `⌘O`), 룩 끄기 · 조정 끄기(`\`)도 목록에서 바꿀 수 있습니다.
- 화살표, `Esc`, `Enter`, `F1`, `?`, `Tab`, 화면 확대/축소(`Ctrl`/`⌘` + `+` `=` `-` `0`), 복사·잘라내기·붙여넣기 키는 바꿀 수 없습니다.
- 치트시트(`?`/`F1`), 툴바 버튼 괄호 안 키, 좌측 레일, 일괄 분류 창, 첫 화면의 **폴더 열기**, LUT 메뉴의 안내 줄이 모두 저장된 키를 표시합니다. 키가 없는 동작은 치트시트에서 빠집니다.
- 단축키는 앱 설정에 저장됩니다.

### 표시 조정 (#130)
단일 보기와 전체화면에 조정 줄이 생겼습니다. **노출**, **색온도**, **대비**, **그레인** 슬라이더로 사진이 화면에 보이는 느낌을 바로 조절할 수 있습니다. 네 값이 모두 0이면 조정 전 화면과 같습니다.
- 보기에만 적용합니다. 원본 파일과 전송한 파일은 바뀌지 않고, 히스토그램도 조정 전 값을 보여줍니다.
- 그리드 썸네일에는 적용하지 않습니다.
- 사진별이 아니라 공통 값으로 적용되고 마지막 값은 앱 설정에 남아 다음에도 이어집니다.
- 룩(LUT)과 함께 켜면 표시 조정을 먼저 적용한 뒤 룩을 씌웁니다. `\`를 누르고 있는 동안 룩과 표시 조정을 함께 끄고 원래 화면과 비교합니다.
- 설정에서 기본값을 복원하면 표시 조정도 화면에서 바로 빠집니다.

### 읽기 전용(프로텍트)만 보기 (#138)
니콘 카메라 바디에서 프로텍트를 걸어 둔 사진(파일 읽기 전용 속성)만 골라 볼 수 있습니다. 좌측 레일의 색 필터 아래와 AI 컬링 창의 **범위** 칸에 **읽기 전용(프로텍트)만** 토글이 생겼습니다.
- 두 곳은 같은 상태를 공유합니다. AI 컬링 창의 토글도 보기 필터만 바꾸고 컬링 시작이나 범위 계산 방식은 그대로입니다.
- 라벨·별점·색 태그 필터와 함께(AND) 적용되고 **필터 초기화**로 한 번에 해제합니다.
- 한 컷에 묶인 RAW·JPG 파일 중 하나라도 읽기 전용이면 프로텍트 컷으로 봅니다. XMP 같은 사이드카 파일은 세지 않습니다.
- 폴더를 열 때 파일 속성을 읽어 기록합니다. 폴더를 연 채로 프로텍트 상태가 바뀌었다면 폴더를 다시 열 때 반영됩니다.

### 바뀐 동작
- **창맞춤 ↔ 1:1 기본 키**: 기본 키가 `Space` 하나가 되었고, v0.7.0까지 함께 쓰던 `Z`는 기본에서 빠졌습니다. `Z`를 계속 쓰려면 설정의 **단축키**에서 다시 지정할 수 있습니다. `Ctrl+Z` / `⌘Z` 되돌리기는 그대로입니다.
- **수식키 일치**: 이제 단축키는 수식키까지 같아야 실행됩니다. `⇧Q`처럼 Shift를 누른 채로는 분류 키가 동작하지 않으며, `\`를 누른 상태에서 `⇧`를 더 누르면 룩과 조정이 다시 보입니다.

・ショートカットの変更:設定の「ショートカット」で各操作のキーを変更できます。QWER・JKLプリセットとショートカット初期化も用意しました。すでに使われているキーを選ぶと2つの操作のキーを入れ替え、チートシートや画面各所のキー表示にも反映されます。
・表示の調整:単一表示と全画面で、露出・色温度・コントラスト・グレインをスライダーで調整できます。表示のみに適用され、元ファイルと転送したファイルは変わらず、ヒストグラムも調整前の値のままです。ルック(LUT)と併用すると表示調整のあとにルックがかかり、\ キーを押している間は両方オフにして比較できます。
・プロテクトのみ表示:ニコンのカメラ本体でプロテクトした写真(読み取り専用ファイル)だけを表示できます。左レールの色フィルタの下とAIカリング画面の「範囲」に「プロテクトのみ」を追加しました。ほかのフィルタとも併用できます。
・動作の変更:フィット / 1:1の既定キーはSpaceのみになりました(Zは既定から外れましたが、設定で再び割り当てられます)。ショートカットはShiftなどの修飾キーまで一致したときだけ実行されます。

- Keyboard Shortcuts: rebind actions in Settings under Keyboard Shortcuts, or switch between the QWER and JKL presets and Reset Shortcuts. Picking a key already in use swaps the two bindings, and key hints across the app and cheat sheet update to match.
- Display adjustments: in single view and fullscreen, adjust Exposure, Temperature, Contrast, and Grain with sliders. Changes affect the display only; originals, transferred files, and the histogram remain unchanged. When combined with a look (LUT), adjustments apply before the look, and holding \ turns both off for comparison.
- Protected Only filter: show only files marked read-only (such as in-camera protected Nikon shots). Toggle Protected Only below Filter Color in the left rail or under SCOPE in the AI Culling dialog; it works alongside your other filters.
- Behavior changes: Fit / 1:1 now defaults to Space only (Z is unassigned by default and can be rebound in Settings). Shortcuts now require an exact modifier match, so holding Shift with a label key will not trigger it.
