## RawBlow v0.5.9

> **다운로드** — Windows(x64): [**Microsoft Store**](https://apps.microsoft.com/store/detail/9PC2FKGPQPD1) 에서 설치하세요(자동 업데이트·보안 경고 없음).
> Microsoft Store를 이용할 수 없는 경우에만 아래 `RawBlow-Setup-v0.5.9.exe` 설치 파일을 받으세요.

### ⚠️ AI 컬링은 테스트 중인 기능입니다
얼굴 검출 · AI 선명도 · 객체 포함 등 ONNX 기반 판정은 **아직 테스트 중이라 오류가 있을 수 있습니다.** 결과를 맹신하지 마세요. 원본 파일은 삭제되지 않으며, 걸러진 컷은 숨김/표시로만 처리됩니다.

### 변경 사항 — 카메라 호환 · UI 렌더링 (#81 · #82 · #83)
- **OM SYSTEM · 올림푸스 지원 (#81)** — OM SYSTEM/올림푸스 ORF의 EXIF가 표시되지 않던 문제와, 구형 올림푸스(E-300 등)의 AF 측거점이 표시되지 않던 문제를 수정했습니다.
- **Pentax K-1 AF 포인트 (#82)** — Pentax K-1로 찍은 사진의 AF 측거점이 표시되지 않던 문제를 수정했습니다.
- **분수 DPI UI 렌더링 (#83)** — 분수(fractional) DPI 배율 환경에서 패널 사이에 흰 줄이 보이던 문제를 수정했습니다.

### Windows 설치
Windows에서는 [**Microsoft Store**](https://apps.microsoft.com/store/detail/9PC2FKGPQPD1) 설치를 권장합니다. 스토어에서 받으면 자동으로 업데이트되고 SmartScreen 경고 없이 실행됩니다.

**Microsoft Store를 이용할 수 없는 경우에만** `RawBlow-Setup-v0.5.9.exe` 를 실행해 설치하세요. 서명 미적용이라 첫 실행 시 SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요. GPU 추론(webgpu) · VC++ 런타임 DLL이 모두 동봉돼 별도 재배포 설치 없이 동작합니다.
