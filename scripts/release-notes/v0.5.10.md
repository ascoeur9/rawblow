## RawBlow v0.5.10

> **다운로드** — Windows(x64): [**Microsoft Store**](https://apps.microsoft.com/store/detail/9PC2FKGPQPD1) 에서 설치하세요(자동 업데이트·보안 경고 없음).
> Microsoft Store를 이용할 수 없는 경우에만 아래 `RawBlow-Setup-v0.5.10.exe` 설치 파일을 받으세요.

### ⚠️ AI 컬링은 테스트 중인 기능입니다
얼굴 검출 · AI 선명도 · 객체 포함 등 ONNX 기반 판정은 **아직 테스트 중이라 오류가 있을 수 있습니다.** 결과를 맹신하지 마세요. 원본 파일은 삭제되지 않으며, 걸러진 컷은 숨김/표시로만 처리됩니다.

### 캐논 CR3 지원 (EOS R 시리즈)
CR3는 다른 RAW와 달리 TIFF가 아니라 ISO BMFF 컨테이너라 메타데이터를 전혀 읽지 못했습니다. `moov` 안의 캐논 메타 블록을 직접 읽도록 해서 한 번에 해결했습니다.

- **세로 사진이 가로로 표시되던 문제 수정** — CR3의 Orientation을 못 읽어 세로 컷이 눕혀 보였습니다. 썸네일·프리뷰·원본 보기 전부 바로 섭니다.
- **EXIF 표시** — 카메라·렌즈·조리개·셔터·ISO·촬영시각이 통째로 비어 있던 문제 수정. 촬영시간순 정렬도 이제 정상 동작합니다.
- **AF 측거점 표시** — CR3의 측거점이 표시되지 않던 문제 수정.

### 방향(가로/세로) 처리
- **AI 컬링의 "세로만/가로만" 필터 수정** — EXIF의 센서 기준 크기를 그대로 써서 **모든 기종에서** 세로 사진을 가로로 분류하던 문제를 수정했습니다.
- 방향 검출 경로를 다시 짜 RAW 한 장당 수십 MB를 읽던 것을 64KB 이내로 줄였습니다(소니 ARW 기준 24ms → 0.1ms).

### 렌즈명 표시
표준 EXIF에 렌즈명이 없는 기종을 제조사 영역에서 읽어 채웁니다.
- **캐논** — EOS 5D(2005) 이후 전 기종.
- **올림푸스/OM SYSTEM** — 구형 포서드(E-300 등)는 렌즈 스펙을 조합해 표시(예: `14-45mm F3.5-5.6`).
- Pentax는 파일에 렌즈명이 기록되지 않아 표시되지 않습니다(제조사 대조표가 필요).

### 뷰어 · UI
- **확대 상태 유지 (#85)** — 사진을 넘겨도 확대·축소 상태가 유지됩니다. 가로↔세로가 바뀌어도 같은 배율로 보이도록 긴 변 기준으로 맞추고, 확대 중 이동하면 원본 화질도 유지합니다.
- **빌드 경고 정리 (#84)** — 향후 Rust 버전에서 오류가 될 예정이던 경고 50건 정리.
- **UI 렌더링 (#83)** — 기본 위젯 일부가 테마 밖 회색으로 그려지던 문제 수정.

### Windows 설치
Windows에서는 [**Microsoft Store**](https://apps.microsoft.com/store/detail/9PC2FKGPQPD1) 설치를 권장합니다. 스토어에서 받으면 자동으로 업데이트되고 SmartScreen 경고 없이 실행됩니다.

**Microsoft Store를 이용할 수 없는 경우에만** `RawBlow-Setup-v0.5.10.exe` 를 실행해 설치하세요. 서명 미적용이라 첫 실행 시 SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요. GPU 추론(webgpu) · VC++ 런타임 DLL이 모두 동봉돼 별도 재배포 설치 없이 동작합니다.
