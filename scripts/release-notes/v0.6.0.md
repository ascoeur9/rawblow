## RawBlow v0.6.0

> **다운로드** — Windows(x64): [**Microsoft Store**](https://apps.microsoft.com/store/detail/9PC2FKGPQPD1) 에서 설치하세요(자동 업데이트·보안 경고 없음).
> Microsoft Store를 이용할 수 없는 경우에만 아래 `RawBlow-Setup-v0.6.0.exe` 설치 파일을 받으세요.
> macOS(Apple Silicon): 아래 `RawBlow-v0.6.0-macos-arm64.zip` 을 받으세요.

### ⚠️ AI 컬링은 테스트 중인 기능입니다
얼굴 검출 · AI 선명도 · 객체 포함 등 ONNX 기반 판정은 **아직 테스트 중이라 오류가 있을 수 있습니다.** 결과를 맹신하지 마세요. 원본 파일은 삭제되지 않으며, 걸러진 컷은 숨김/표시로만 처리됩니다.

### 셀렉을 이어서 (#86)
**폴더별로 마지막에 보던 사진에서 다시 시작합니다.** 수백 장을 며칠에 걸쳐 셀렉할 때 매번 첫 장부터 스크롤할 필요가 없습니다.

- 폴더마다 따로 기억하므로, 여러 폴더를 오가도 각자의 위치로 돌아갑니다.
- 배열 순서가 아니라 **파일 경로**를 기억합니다 — 파일을 추가·삭제하거나 정렬을 바꿔도 같은 사진을 집습니다.
- 기억해 둔 사진이 사라졌거나 현재 필터에 걸러지면 조용히 첫 장에서 시작합니다.

### 확대·배율 (#48)
프리뷰와 원본 보기(ORIG)를 `D`로 오갈 때 **화면에 보이는 크기와 상태바의 배율이 모두 그대로 유지됩니다.**

- 확대해서 픽셀을 확인하다 `D`를 눌러도 배율이 줄어들거나 되돌아오지 않던 문제 수정.
- **상태바의 % 가 실제 배율을 가리킵니다.** 100%가 원본 1픽셀 = 화면 1픽셀(실측 1:1)이고, 표시 해상도가 바뀌어도 사진 크기가 같으면 숫자도 같습니다.
- 니콘 NEF처럼 파일의 EXIF에 축소 썸네일 크기(160x120)가 적혀 있는 기종에서 배율이 100%↔23%로 튀고 `Space`(1:1)가 실제 1:1에 도달하지 못하던 문제 수정 — 원본 해상도를 파일에서 직접 실측합니다.
- `Space`·툴바 `1:1`·사진 클릭이 모두 **실측 1:1**로 통일되고, 원본 보기도 함께 켜집니다(프리뷰를 늘려 놓고 100%라 부르면 뿌옇기만 하고 픽셀 확인이 안 되기 때문).

### 초점거리로 정리 (#92)
폴더 자동 분류에 **초점거리** 기준이 추가됐습니다. 1mm 단위로 `35mm`, `85mm` 같은 하위폴더를 만듭니다(어안 10.5mm는 `11mm`로 반올림). EXIF를 읽을 수 없는 파일은 `unknown-focal`로 모입니다. 기존 기준과 마찬가지로 RAW+JPG 페어는 같은 폴더에 유지됩니다.

### 사진 이동 시 원본 보기 (#87)
설정에 **「사진 이동 시 원본 보기」** 항목이 생겼습니다.

- **확대 중일 때만 유지** (기본값, v0.5.10과 동일) — 확대 중이면 원본 보기를 유지하고, 창맞춤이면 가벼운 프리뷰로 돌아갑니다.
- **현재 보기 상태 유지** — 창맞춤이어도 계속 원본 해상도로 봅니다. 넘김이 느려지고 메모리를 더 쓰는 대신, 화질을 계속 원본으로 확인할 수 있습니다.

설정을 건드리지 않으면 기본값이라 기존 사용법 그대로입니다. 또한 필름스트립 클릭 · 그리드 클릭 · 점프 대화상자가 화살표 이동과 다르게 동작하던 것을 통일했습니다.

### Windows 설치
Windows에서는 [**Microsoft Store**](https://apps.microsoft.com/store/detail/9PC2FKGPQPD1) 설치를 권장합니다. 스토어에서 받으면 자동으로 업데이트되고 SmartScreen 경고 없이 실행됩니다.

**Microsoft Store를 이용할 수 없는 경우에만** `RawBlow-Setup-v0.6.0.exe` 를 실행해 설치하세요. 서명 미적용이라 첫 실행 시 SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 누르세요. GPU 추론(webgpu) · VC++ 런타임 DLL이 모두 동봉돼 별도 재배포 설치 없이 동작합니다.

### macOS 설치 — 처음 실행 시 (중요)
Apple Silicon(arm64) Mac에서 `RawBlow-v0.6.0-macos-arm64.zip` 을 받아 압축을 풀면 `RawBlow.app` 이 나옵니다.

이 앱은 ad-hoc 서명만 되어 있고 공증(notarize)되지 않았습니다. macOS 15+ 에서는 우클릭→열기가 통하지 않으니, **터미널**에서 압축 해제 후 아래를 실행하세요:

```text
xattr -dr com.apple.quarantine RawBlow.app
```
