**RAW 사진을 빠르게 넘기며 골라내는 셀렉 뷰어.** Rust + egui/wgpu 네이티브 · Windows / macOS / Linux

수천 장의 RAW를 빠르게 넘기며 채택·보류·제외로 분류하고, 고른 사진만 복사하거나 옮기는 가벼운 셀렉 도구입니다. 평소에는 RAW 안에 들어 있는 임베디드 프리뷰를 바로 띄워 넘김이 빠르고, 초점과 디테일을 정밀하게 볼 때만 원본 해상도를 불러옵니다. 분류 결과는 원본을 건드리지 않고 폴더 안 사이드카 파일에만 기록합니다.

윗 문단은 AI가 쓴 설명글이고, RawBlow는 사실 라룸에서 로우 올려 셀렉하다가 너무 느려서 화가 난 나머지 화를 주체하지 못하고 책상을 내리치려다 에임 이슈로 제 낭심을 내려친 고통을 참지 못하고 만든 개빠른 로우 뷰어 / 셀렉툴입니다...

쉽고 빠른 셀렉을 위한 여러 가지 기능을 계속 추가하고 있지만, 우선 '빠른 셀렉' 을 0순위로 둡니다.

---

## 기본 흐름

1. 폴더를 엽니다. 좌상단 **폴더 열기** 버튼, `⌘/Ctrl+O`, 창에 폴더를 끌어다 놓기 중 편한 것을 쓰면 됩니다.
2. `←` `→`로 넘기면서 `Q`(채택) `W`(보류) `E`(제외)를 누릅니다. 별점 `1`~`5`와 컬러 태그 `⇧1`~`⇧5`는 라벨과 별개 축이라 함께 매길 수 있습니다.
3. 좌측 레일에서 보고 싶은 조합만 남겨 확인한 뒤, `Enter`로 전송 창을 열어 고른 파일만 복사하거나 옮깁니다.

분류하는 동안 원본 파일은 그대로 있습니다. 라벨·별점·태그는 폴더 안 `.rawblow/session.json`에만 쌓이고, 폴더를 다시 열면 그대로 복원됩니다.

## 주요 기능

### 보기와 넘김

- **단일뷰와 그리드.** 아래 필름스트립이 붙은 단일뷰와 썸네일 그리드를 `T`로 오갑니다. 그리드 열 수는 설정에서 4~12장 사이로 정합니다.
- **확대.** 사진을 클릭하면 창맞춤과 1:1을 오갑니다. `Ctrl`+휠이나 터치패드 핀치로 연속 확대하고, 확대한 상태에서는 드래그로 움직입니다. 배율은 우측 하단에 나오며 100%가 원본 1픽셀 대 화면 1픽셀입니다. 사진을 넘겨도 확대 상태가 유지됩니다.
- **원본 보기(ORIG).** 임베디드 프리뷰 대신 RAW를 원본 해상도로 디코딩해 실제 디테일을 봅니다. `D` 또는 툴바 **ORIG** 버튼으로 켜며, 파일에 따라 로딩이 조금 걸립니다. 사진을 넘길 때 원본 보기를 계속 유지할지는 설정에서 고릅니다.
- **오버레이.** `I`로 EXIF, `H`로 RGB 히스토그램, `A`로 카메라가 잡은 AF 측거점, `M`으로 GPS가 기록된 사진의 촬영 위치 미니 지도를 켭니다.
- **사진 배경색.** 표시 화면 배경을 프리셋(검정, 회색 3단계, 흰색)이나 HEX·RGB 직접 입력으로 바꿉니다. 라이트룸 현상 모듈 기본값인 50% 회색도 프리셋에 있습니다.
- **전체화면.** `F11` 또는 툴바 **Full** 버튼. 단일뷰든 그리드든 전체화면에서도 넘김·확대·원본 보기 단축키가 그대로 동작합니다.
- 세로/가로 자동 회전, RAW+JPG 페어링, RAW+ 배지를 지원합니다.

### 분류

- **라벨.** `Q` 채택, `W` 보류, `E` 제외, `R` 해제. 같은 키를 다시 누르면 풀립니다. 라벨을 매기면 자동으로 다음 장으로 넘어가며, 설정에서 끌 수 있습니다.
- **별점.** `1`~`5`로 매기고 `` ` ``(백틱)으로 해제합니다. 라벨과 독립된 축이라 동시에 붙습니다.
- **컬러 태그.** `⇧1`~`⇧5`로 주황·분홍·청록·파랑·보라를 붙이고 `⇧0`으로 뗍니다. 라벨·별점과 독립입니다. 설정에서 색마다 이름을 지정하면(보정 방식 등) 필터·전송·파일명에 그 이름이 따라갑니다.
- **그리드 다중 선택.** `Ctrl`(`⌘`)+클릭으로 하나씩 토글하고, 클릭한 뒤 `Shift`+클릭으로 범위를 잡습니다. 고른 것을 `Q` `W` `E` `R`이나 별점으로 한꺼번에 분류합니다.
- **일괄 분류.** 그리드에서 `B`. 파일명이나 그 일부를 줄바꿈·쉼표·탭으로 구분해 붙여 넣으면 맞는 항목을 찾아 라벨을 한 번에 적용합니다.
- **되돌리기.** `⌘/Ctrl+Z`로 되돌리고 `⌘/Ctrl+⇧Z` 또는 `⌘/Ctrl+Y`로 다시 실행합니다.
- **비파괴 저장.** 라벨·별점·컬러 태그는 폴더 안 `.rawblow/session.json`에 저장되며 사람이 읽는 txt도 함께 나옵니다. 원본 파일은 손대지 않습니다.

### 골라 보기

- **필터.** 좌측 레일에서 라벨, 별점(정확히 N점), 컬러 태그를 각각 고릅니다. 셋은 서로 독립이며 AND로 겹쳐 걸립니다. 라벨 필터만 순환하려면 `F`.
- **점프.** `G`로 순번이나 파일명 일부를 입력해 한 번에 이동합니다.
- **폴더별 이어보기.** 폴더마다 마지막으로 보던 사진을 기억해 다시 열면 그 자리에서 시작합니다. 배열 순서가 아니라 파일 경로를 기억하므로 파일을 더하거나 지워도, 정렬을 바꿔도 같은 사진을 집습니다.
- **정렬.** 촬영시간순이 기본이고 설정에서 파일명순으로 바꿉니다. 여러 카메라를 섞어 쓰면 파일명이 촬영 순서와 어긋나기 때문입니다.

### AI 컬링 (테스트 중)

> **모델이 판정하는 항목은 아직 테스트 중입니다.** 얼굴 검출, AI 선명도, 객체 포함 같은 판정에는 오류가 있을 수 있으니 결과를 그대로 믿지 마세요. 원본 파일은 삭제되지 않고, 걸러진 컷도 라벨·별점·태그 값만 바뀝니다.

사진을 분석해 좋음과 탈락을 자동으로 매깁니다. 결과는 라벨·별점·컬러 태그 중 지정한 축 하나에만 들어가므로 손으로 매긴 축은 건드리지 않습니다. 분석은 전부 이 컴퓨터 안에서 돌고 백그라운드로 진행되며, 도중에 취소할 수 있습니다.

- **모델 없이 도는 기준.** 초점(선명도), 노출, 수평 기울기. 초점은 프레임 전체 대신 카메라가 잡은 AF 측거점 영역만 볼 수도 있습니다.
- **메타데이터 기준.** 세로/가로, ISO 상한, 초점거리 범위, 조리개 상한, 셔터속도 하한, 카메라·렌즈 이름 부분일치.
- **연사 베스트-N.** 정한 간격 안에 찍힌 컷을 한 묶음으로 보고 그중 점수 상위 N장만 남깁니다.
- **중복 정리.** 거의 같은 장면을 퍼셉추얼 해시로 묶어 묶음당 베스트만 남깁니다.
- **모델이 필요한 기준.** 미적 점수(CLIP-IQA), AI 선명도, 장르 픽(인물/풍경), 얼굴 검출(YuNet), 객체 검출(YOLOv10n). 모델은 처음 쓸 때 자동으로 내려받고 sha256로 검증합니다.
- **GPU 가속.** Windows는 WebGPU, macOS는 CoreML을 씁니다. 등록에 실패하면 조용히 CPU로 떨어집니다.

### 내보내기

- **전송.** 고른 파일만 복사하거나 옮깁니다. 라벨, 별점, 컬러 태그로 대상을 정하며 셋 중 하나라도 걸리면 대상이 됩니다(합집합). 라벨·태그별 하위폴더로 나누기, 동반 파일 처리, 이름 충돌 시 일련번호를 고를 수 있습니다. 옮기기를 쓰면 옮겨진 항목이 목록에서 자동으로 빠집니다. 진행률 표시와 취소 버튼이 있어 큰 폴더나 느린 드라이브에서도 멈춘 것처럼 보이지 않습니다.
- **전송 시 이름 변경.** 순번(1, 2, 3), 별점등급(A1, B1 …), 직접 템플릿 중에서 고릅니다. 템플릿에는 `{seq}` `{gradeseq}` `{grade}` `{stars}` `{label}` `{tag}` `{orig}`를 쓰고 `{seq:03}`처럼 0 패딩을 붙입니다. 미리보기가 실시간으로 나오며 RAW+JPG 페어는 같은 이름을 받습니다.
- **폴더 정리.** 좌측 레일 아래 **정리** 버튼으로 폴더 안 사진을 촬영일, 카메라, 렌즈, 초점거리, 확장자 기준 하위폴더에 나눠 담습니다(이동 또는 복사). EXIF 기준은 RAW+JPG 페어를 같은 폴더에 유지하고, EXIF를 읽을 수 없는 파일은 `unknown-date` 같은 폴더로 모입니다. 정리한 폴더를 바로 열어 셀렉할 수 있으며 전송과는 별개 기능입니다.

### 그 밖에

- **빠른 로딩.** 임베디드 프리뷰를 화면 크기에 맞춰 축소 디코딩하고, 백그라운드 디코딩과 전방 프리로드, LRU 텍스처 캐시를 함께 씁니다.
- **썸네일 디스크 캐시.** 한 번 디코딩한 썸네일은 OS 캐시에 남아 폴더를 닫았다 다시 열어도 재디코딩 없이 뜹니다. 설정에서 사용량을 확인하고 비울 수 있으며, 상한(기본 1GB, 0이면 무제한)을 넘으면 오래된 것부터 지웁니다.
- **다국어.** 한국어 / English / 日本語. OS 언어를 따라가고 설정에서 바꾸면 저장됩니다.
- **단축키 치트시트.** `?` 또는 `F1`로 앱 안에서 전체 단축키를 봅니다.
- **새 버전 안내.** 실행 후 유휴 시 GitHub 최신 릴리즈를 확인해, 새 버전이 있으면 좌측 레일에 안내 버튼을 띄웁니다. 설정에서 끌 수 있습니다.
- **오픈소스 라이선스 고지.** 설정 화면에서 포함된 구성요소 목록과 라이선스 전문을 봅니다.

## 설치

### Windows (권장: Microsoft Store)

[**Microsoft Store에서 받기**](https://apps.microsoft.com/store/detail/9PC2FKGPQPD1). 스토어에서 설치하면 자동으로 업데이트되고 보안 경고 없이 바로 실행됩니다.

Microsoft Store를 이용할 수 없을 때만 [**Releases**](https://github.com/ascoeur9/rawblow/releases/latest)에서 `RawBlow-Setup-vX.Y.Z.exe`를 받으세요. 필요한 런타임이 모두 들어 있어 따로 설치할 것은 없습니다. 코드 서명이 없어 첫 실행 시 SmartScreen이 "Windows의 PC 보호"를 띄우면 **추가 정보 → 실행**을 누르면 됩니다.

### macOS (Apple Silicon)

[**Releases**](https://github.com/ascoeur9/rawblow/releases/latest)에서 `RawBlow-vX.Y.Z-macos-arm64.zip`을 받아 압축을 풀면 `RawBlow.app`이 나옵니다.

공증(notarize)을 받지 않아 처음 실행할 때 "확인되지 않은 개발자" 경고가 뜹니다. 경고창에서 **완료**를 누른 뒤 **시스템 설정 → 개인정보 보호 및 보안 → 보안** 맨 아래의 **그래도 열기**를 누르세요. macOS 15 Sequoia부터는 예전의 우클릭 → 열기 우회가 더 이상 동작하지 않습니다. 터미널을 쓴다면 아래 한 줄로도 됩니다.

```bash
xattr -dr com.apple.quarantine /Applications/RawBlow.app
```

### 소스에서 빌드 (Linux, 그 외)

```bash
cargo build --release -p rawblow-app   # 실행물: target/release/rawblow(.exe)
cargo run   --release -p rawblow-app
```

Rust 1.80 이상, C 링커(MSVC Build Tools / gcc / clang)가 필요하고 Linux는 Vulkan 런타임이 있어야 합니다. 한글 폰트는 OS 폰트에서 자동으로 불러옵니다.

배포용 클린 릴리스 빌드(단독 실행 + 빌드 경로·사용자명 제거)는 [`BUILD.md`](BUILD.md)를 보세요.

## 지원 포맷과 확인된 카메라

RAW는 `.ARW` `.CR2` `.CR3` `.NEF` `.ORF` `.RW2` `.RAF` `.DNG` `.PEF` `.SRW` `.RAW`, 일반 이미지는 `.JPG` `.JPEG` `.PNG` `.WEBP` `.HEIC` `.HEIF` `.TIF` `.TIFF`를 읽습니다.

**OS.** Windows 11과 macOS(Apple Silicon)로 정식 배포합니다. Linux는 코드상 지원하지만 사전 빌드본을 제공하지 않으니 소스에서 빌드하세요.

아래 목록에 없는 바디도 동작하도록 만들었지만, 검증하지 않은 바디는 임베디드 프리뷰 경로로 표시됩니다. 새 바디에서 회색 화면이나 깨짐, 오류가 보이면 꼭 알려주세요.

### 실파일로 확인한 카메라

| Nikon | `.NEF` | Z6III, Z8, Z30, Z50II, D850 |

## 알려진 한계

- 컬러 매니지먼트는 임베디드 ICC에서 sRGB까지입니다. 모니터 ICC 프로파일은 조회하지 않고 sRGB로 가정합니다.
- 단축키를 다시 지정하는 화면이 없습니다. 기본값 고정입니다.
- HEIC 등 일부 포맷은 플랫폼 디코더에 기댑니다.
- 원본 보기는 GPU 텍스처 한계(긴 변 약 8192픽셀) 안에서 표시합니다.
- 펜탁스는 파일 어디에도 렌즈명이 기록되지 않아 렌즈 항목이 비어 있습니다.
- AI 컬링 중 모델이 판정하는 항목은 테스트 단계입니다.
