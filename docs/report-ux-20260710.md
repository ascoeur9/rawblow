- [ ] **1-2**: `save_sidecar_if_due`의 NLL 차용 패턴(`&self.folder` 차용 종료 후 `&mut self` 호출) — 표준 NLL 허용 형태지만 컴파일로 확인.
- [ ] **1-3**: Move 확인 카드가 `Order::Tooltip` 레이어 — dim(Foreground)이 카드를 덮지 않게 한 단계 위에 배치. egui 0.29에서 Tooltip 레이어의 버튼이 클릭을 받는지 **실행으로 확인**(키보드 Enter/Esc 폴백은 항상 동작). 문제 시 카드도 Foreground로 내리고 dim보다 나중에 show.
- [ ] **1-3**: Enter 시작의 `typing` 가드(직전 프레임 포커스 기준) — 대상 폴더/템플릿 입력 중 Enter가 시작으로 오인되지 않는지 실행 확인.
- [ ] **2-1**: `egui::Key::Questionmark` — egui 0.29 존재 여부를 컴파일로 확인. **없으면 두 곳을 삭제**: ① app.rs `handle_keys`의 `Key::Questionmark => …` arm ② dialogs.rs `ui_help` 닫기 체크의 `|| i.key_pressed(egui::Key::Questionmark)` (Slash+shift·F1·Esc 경로는 그대로 동작). `ui.horizontal_top`도 레포 첫 사용(표준 API, 저위험).
- [ ] **3-B/3-C**: `RichText::new({ #[cfg]{..} #[cfg(not)]{..} })` cfg-블록-표현식(has_modal과 동일 관례), 다운로드 루프의 `drop(file); return;`, ▸/▾(U+25B8/25BE) 글리프 렌더(▶은 이미 사용 중) — 컴파일·실행으로 확인.
- 나머지 API는 전부 레포 기존 사용 패턴 답습(`Frame…show().response.interact()`, `set_cursor_icon`, let-else, `TransferReport`의 `derive(Default)` 확인 등 — 선례 확인함).
