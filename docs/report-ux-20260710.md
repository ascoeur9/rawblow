## 항목별 구현 내역 · 검증 체크리스트

### 1-1. 토스트 오버레이 렌더링 (#61)

**구현**: `toast` 필드를 `Option<Toast>`(text·at·kind)로 교체, `ToastKind::{Info(3s)/Notice(6s)/Error(자동만료 없음)}` + 헬퍼 `toast_info/notice/error`. 세터 15곳 전부 헬퍼로 이관(Error=다운로드 실패 1곳, Notice=컬링 완료·결과 폐기 2곳, 나머지 Info 12곳). `views.rs::ui_toast` 신설 — `Order::Foreground`, 우하단 앵커(상태바 위 12px), BG3 카드 + 심각도 점(REJECT/ACCENT/INK3), 최대 폭 380 줄바꿈, 클릭으로 닫기(Error는 ✕ 표시). `update()` 맨 끝에서 호출. `ToastKind::duration` 단위테스트 추가.

**빌드머신 수동 체크**:
- [ ] 폴더 열기 → 우하단 "N 항목 로드" 3초 표시
- [ ] G(점프)에서 없는 파일명 → "매칭 없음"
- [ ] AI 컬링 중 Q/W/E → "…잠겨 있습니다" 안내 표시
- [ ] 오프라인에서 모델 다운로드 → 빨간 점 + "다운로드 실패: …"가 **자동으로 사라지지 않고** 클릭으로 닫힘
- [ ] 전송 다이얼로그(모달 딤) 위에서도 토스트가 가려지지 않는지
- [ ] 다국어(En/Ja)에서 메시지 번역 표시
