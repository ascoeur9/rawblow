합칠 때 정한 것
- 표시 조정과 룩의 적용 순서: 「표시 조정 → 룩」 순서로 적용함(그레인도 룩을 거침)
- `\` 동작: `\`를 누르고 있는 동안 룩과 표시 조정을 둘 다 끔. 설정·치트시트 줄 이름은 「룩 끄기 · 조정 끄기」
- 단축키 충돌 처리: 이미 다른 동작이 쓰는 키를 지정하면 맞바꿈(바꾸는 동작에 키가 없었으면 밀려난 동작은 키 없음이 됨; 키가 둘인 동작은 해당 키만 잃고 맞바꾸지 않음; 한 키에 동작이 둘 붙는 상태는 생기지 않음)
- 설정 단축키 목록에 새로 들어간 동작: 전에는 고정 키였던 구도선 `]`, 일괄 분류(그리드) `B`, 폴더 열기 `Ctrl+O`/`⌘O`, 룩 끄기 · 조정 끄기 `\`를 목록에 넣음
- 새로 막은 고정 키: 화살표, `Esc`, `Enter`, `F1`, `?`, `Tab`, `Ctrl`/`⌘` + `+` `=` `-` `0`, 복사·잘라내기·붙여넣기 키(`Ctrl`/`⌘`+`C`·`X`·`V` 등)는 바꿀 수 없게 막음
- 창맞춤 ↔ 1:1 키: 기본 키는 `Space` 하나임. v0.7.0까지 되던 `Z`는 기본에서 빠짐(설정에서 다시 지정 가능, `Ctrl+Z`/`⌘Z` 되돌리기는 그대로)
- 수식키 일치: 단축키는 수식키까지 같아야 실행함(예: `⇧Q`는 채택 아님, `\`를 누른 채 `⇧`를 더 누르면 룩과 조정이 다시 보임)
- 기본값 복원 직후 조정 제거: 설정의 기본값 복원을 누르면 표시 조정이 화면에서 바로 빠짐

## 3. 단축키 변경 (#132 / 이슈 #123)

위치: 설정 → 「단축키」 섹션.

| 확인 | 맥 | 윈도우 |
|---|---|---|
| 동작 행의 「바꾸기」 클릭 → 키캡이 `…`로 바뀌고 버튼이 「취소」가 됨. 원하는 키 입력 → 즉시 지정·저장됨 (「취소」 또는 `Esc`로 대기 취소, 대기 중 `Esc`는 설정을 닫지 않음) | | |
| 프리셋 3개 순서대로 클릭: 「JKL」(채택 `J`·보류 `K`·제외 `L`·해제 `U`, 나머지 기본) → 「QWER」(기본 QWER) → 키 일부 변경 후 「단축키 초기화」(전체 기본값 복귀) → 각각 의도대로 바뀜 | | |
| 「채택」(Q)에 `W` 지정 → 채택 `W`, 「보류」 `Q`로 맞바뀌고 채택 행 바로 아래에 「보류 키가 바뀌었습니다」 + `Q` 키캡이 한 줄로 표시됨. 안내 줄 폭이 잘리거나 깨지지 않음. 한 키에 동작이 둘 붙지 않음 | | |
| 키 없는 동작(「없음」 표시)에 다른 동작이 쓰는 키 지정 → 밀려난 동작이 「없음」이 되고 바꾼 행 아래에 「○○ 키가 풀렸습니다」 표시 | | |
| 「다시 실행」(키 2개: `Ctrl+⇧Z`/`⌘⇧Z`, `Ctrl+Y`/`⌘Y`)이 쓰는 키 하나를 다른 동작에 지정 → 「다시 실행」은 그 키만 잃고 나머지 키를 유지하며 맞바꾸지 않음 | | |
| 새로 목록에 들어간 동작 4개(구도선 `]`, 일괄 분류(그리드) `B`, 폴더 열기 `Ctrl+O`/`⌘O`, 룩 끄기 · 조정 끄기 `\`)를 다른 키로 지정 → 바꾼 키로 실제 동작함 | | |
| 「바꾸기」 대기 중 고정 키 입력(화살표, `Enter`, `F1`, `?`, `Tab`, `Ctrl`/`⌘`+`+`/`=`/`-`/`0`, `Ctrl`/`⌘`+`C`·`X`·`V`[클립보드에 내용 있을 때]) → 지정되지 않고 토스트 「이 키는 바꿀 수 없습니다」 표시 후 계속 키 대기 | | |
| (알려진 한계 확인) 클립보드가 빈 상태에서 `Ctrl`/`⌘`+`V` 입력 → 안내 없이 계속 키를 기다리고 지정되지 않음 | | |
| 실제 키 입력·표기: 맥 `⌘` 조합과 `⌘`·`⌥`·`⇧` 키캡 글꼴 깨짐 없음 / 윈도우 `Ctrl+` 조합 표기와 입력 정상 | | |
| 한국어·일본어 자판 상태에서 `\`(한국어 ₩ 자리 포함)·`]` 입력과 재지정 정상 동작 | | |
| 분류·보기·구도선·폴더 열기·룩 끄기 키를 바꾼 뒤 확인 → 치트시트(`?`/`F1`), 툴바 버튼 괄호 안 키, 좌측 레일 키 표시, 일괄 분류 창 라벨 버튼, 첫 화면 「폴더 열기」 키, LUT 메뉴 안내 줄이 모두 바뀐 키를 표시함 | | |
| 키가 없는 동작(「없음」) → 치트시트에서 해당 줄이 빠짐 | | |
| 기본 설정 단일 보기에서 `Z` 입력 → 창맞춤 ↔ 1:1이 실행되지 않고 `Space`로만 전환됨. 설정에서 `Z`를 다시 지정하면 동작함. `Ctrl+Z`/`⌘Z` 되돌리기는 그대로 동작함 | | |
| 단일 보기에서 `⇧Q` 입력 → 채택이 실행되지 않음(수식키 일치). `\`를 누른 채 `⇧`를 더 누르면 룩과 조정이 다시 보임 | | |
| 단축키를 바꾼 뒤 앱 종료 후 재실행 → 바꾼 키가 그대로 유지됨 | | |

| 확인 | 맥 | 윈도우 |
|---|---|---|

| 그리드 보기 전환 → 조정 줄이 없고 썸네일에 조정이 적용되지 않음 | | |
| 조정을 크게 건 상태에서 히스토그램(`H`) 확인 → 조정 전과 모양이 같음 | | |
| 조정을 건 상태에서 사진 전송(복사·이동) → 전송된 파일이 원본과 바이트 동일함 | | |
| 표시 조정과 LUT·내장 룩을 함께 켬 → 「표시 조정 → 룩」 순서로 적용된 색이 보이고, 그레인도 룩을 거침 | | |
| 조정과 룩을 함께 켠 상태에서 `\` 누르고 있기 → 둘 다 꺼져 원래 화면이 보이고, 떼면 둘 다 돌아옴 | | |
| 룩 「없음」·표시 조정만 적용한 상태에서 설정 → 「초기화」 → 「기본값」 → 「복원」(2단 확인) → 설정에서 돌아오면 조정이 화면에서 바로 빠짐 | | |
| 한국어(「룩 끄기 · 조정 끄기」)·영어(「Look off · Adjustment off」)·일본어(「ルックオフ · 調整オフ」)에서 치트시트(`?`/`F1`) 확인 → `\` 줄이 오른쪽 열 폭에 들어가고 마지막 줄까지 보임 | | |
