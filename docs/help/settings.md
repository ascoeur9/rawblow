# 설정 · 단축키

툴바 오른쪽 **⚙** (툴팁 **설정**)으로 엽니다. 헤더는 **설정 — 키보드 · 일반**입니다. 단축키는 설정 화면의 **단축키** 구역에서 바꿀 수 있습니다.

<!-- SCREENSHOT-PLACEHOLDER: settings -->

> **캡처 지시 (Windows / macOS)**
>
> - **창:** RawBlow 설정 화면. 헤더 `설정 — 키보드 · 일반`, 왼쪽 위 `← 돌아가기`.
> - **준비:** ⚙를 눌러 설정을 엽니다. 한국어. 한 화면에 **일반**(라벨링 후 자동 전진, 하위 폴더 포함 스캔, EXIF/히스토그램 기본 표시, 새 버전 자동 확인, 프리로드, 그리드 열 수, 정렬, 사진 이동 시 원본 보기, 언어)이 보이게 창을 높게 잡습니다. 아래 **사진 배경**, **라벨**, **색 태그 이름**, **캐시**는 스크롤해 두 번째 장으로 찍어도 됩니다.
> - **찍을 컨트롤:** 설정 본문. 첫 장은 일반 구역 전체, 둘째 장은 사진 배경 프리셋(기본/검정/회색/흰색)과 캐시 사용량·**캐시 비우기**.
> - **크롭:** 설정 패널만. 뒤 사진이 비치면 자릅니다. 색 태그 이름에 개인용 메모를 넣었다면 기본 이름(주황 등)인 상태로 찍습니다.
> - **넣기:** 이 블록을 PNG로 바꿉니다.

## 사진 배경 · 색 태그 이름

사진 표시 영역 배경은 프리셋 또는 HEX/RGB입니다. 라이트룸 현상 모듈 기본값 50% 회색은 **중간 회색**입니다.

색 태그 이름은 색마다 입력합니다. 안내: `색별 이름을 지정해 보정 방식 등 나만의 분류로 — ⇧1~5로 부여`.

## 캐시

한 번 디코딩한 썸네일은 디스크 캐시에 남아 폴더를 다시 열어도 재디코딩 없이 뜹니다.

- Windows: `%LOCALAPPDATA%\RawBlow\thumb-cache`
- macOS: OS 캐시 디렉터리 아래 RawBlow

**자동 상한** 기본은 1024MB(1GB)입니다. 0이면 무제한입니다. 상한을 넘으면 오래된 썸네일부터 지웁니다. 폴더를 열 때와 설정을 바꿀 때 정리됩니다. **캐시 비우기**로 지금 비울 수 있습니다.

### 단축키 바꾸기

설정 화면의 **단축키** 구역에서 동작마다 단축키를 다시 지정할 수 있습니다.

1. 바꿀 동작 행에서 **바꾸기**를 누릅니다.
2. 원하는 키를 누르면 바로 지정되고 저장됩니다. 기다리는 중에 **취소**나 `Esc`를 누르면 취소됩니다.

- **프리셋:** 구역 상단의 **QWER**, **JKL**, **단축키 초기화**로 한 번에 바꿀 수 있습니다. **단축키 초기화**와 **QWER**은 기본 키로 돌립니다. **JKL**은 채택 `J`, 보류 `K`, 제외 `L`, 해제 `U`로 바꾸며 나머지는 기본 키와 같습니다.
- **이미 쓰는 키 지정(맞바꿈):** 다른 동작이 쓰는 키를 지정하면 원래 그 키를 쓰던 동작이 지금 바꾸는 동작의 직전 키를 받습니다. 예를 들어 채택(`Q`)에 `W`를 지정하면 채택은 `W`, 보류는 `Q`가 되고 바꾼 행 바로 아래에 `보류 키가 바뀌었습니다`와 새 키가 한 줄로 나옵니다. 한 키에 동작이 둘 붙지는 않습니다. 밀려난 동작에 다른 키가 남아 있으면(**다시 실행**처럼 키가 둘인 동작) 그 키만 빠지고 맞바꾸지 않습니다.
- **키 없음:** 원래 키가 없던 동작에 다른 동작이 쓰던 키를 지정하면 밀려난 동작은 키가 비고 행에 **없음**이 표시됩니다. 바꾼 행 아래에는 `○○ 키가 풀렸습니다`가 나옵니다.
- **바꿀 수 없는 키:** 화살표(`←` `→` `↑` `↓`), `Esc`, `Enter`, `F1`, `?`, `Tab`, `Ctrl`/`⌘` + `+` `=` `-` `0`, 복사·잘라내기·붙여넣기(`Ctrl`/`⌘` + `C` `X` `V` 등)는 지정할 수 없습니다. 이 키를 누르면 **이 키는 바꿀 수 없습니다**가 뜹니다.
- **수식키 일치:** 단축키는 수식키까지 같아야 실행됩니다. 예를 들어 `⇧Q`를 눌러도 채택(`Q`)은 실행되지 않으며, `\`를 누른 채 `⇧`를 더 누르면 룩이 다시 보입니다.
- **화면 표시 반영:** 단축키 치트시트(`?`/`F1`), 툴바 버튼의 괄호 안 키, 좌측 레일의 키 표시, 일괄 분류 창의 라벨 버튼, 첫 화면의 **폴더 열기** 키, LUT 메뉴의 안내 줄은 모두 저장된 키를 따릅니다. 키가 없는 동작은 치트시트에서 줄이 빠집니다.
- **설정 목록과 저장 위치:** 구도선(`]`), 일괄 분류(`B`), 폴더 열기(`Ctrl+O`/`⌘O`), 룩 끄기 · 조정 끄기(`\`)도 이 목록에서 바꿀 수 있습니다. 바꾼 단축키는 사진 폴더가 아니라 OS 설정 폴더의 앱 설정에 저장됩니다.

## 네트워크를 쓰는 설정

앱은 계정·로그인이 없고, 아래를 쓸 때만 인터넷에 연결합니다.

1. **새 버전 자동 확인** (끌 수 있음). GitHub API만 조회합니다. 사진은 올리지 않습니다.
2. **촬영 위치 지도** (`M`). GPS가 있는 사진의 지도 타일을 OpenStreetMap에 요청합니다.
3. **AI 컬링 모델 다운로드**. GitHub Releases의 모델 파일만 받습니다. 사진은 올리지 않습니다.

자세한 항목은 저장소의 `PRIVACY.md`를 봅니다.
