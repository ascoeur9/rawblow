# 설정 · 단축키

툴바 오른쪽 **⚙** (툴팁 **설정**)으로 엽니다. 헤더는 **설정 — 키보드 · 일반**입니다. 단축키를 다시 지정하는 화면은 없습니다. 기본값 고정입니다.

<!-- SCREENSHOT-PLACEHOLDER: settings -->

> **캡처 지시 (Windows / macOS)**
>
> - **창:** RawBlow 설정 화면. 헤더 `설정 — 키보드 · 일반`, 왼쪽 위 `← 돌아가기`.
> - **준비:** ⚙를 눌러 설정을 엽니다. 한국어. 한 화면에 **일반**(라벨링 후 자동 전진, 하위 폴더 포함 스캔, EXIF/히스토그램 기본 표시, 새 버전 자동 확인, 프리로드, 그리드 열 수, 정렬, 사진 이동 시 원본 보기, 언어)이 보이게 창을 높게 잡습니다. 아래 **사진 배경**, **라벨**, **색 태그 이름**, **캐시**는 스크롤해 두 번째 장으로 찍어도 됩니다.
> - **찍을 컨트롤:** 설정 본문. 첫 장은 일반 구역 전체, 둘째 장은 사진 배경 프리셋(기본/검정/회색/흰색)과 캐시 사용량·**캐시 비우기**.
> - **크롭:** 설정 패널만. 뒤 사진이 비치면 자릅니다. 색 태그 이름에 개인용 메모를 넣었다면 기본 이름(주황 등)인 상태로 찍습니다.
> - **넣기:** 이 블록을 PNG로 바꿉니다.

## 사진 배경 · 색 태그 이름

사진 표시 영역 배경은 프리셋 또는 HEX/RGB입니다. 라이트룸 현상 모듈 기본값 50% 회색은 **중간 회색**입니다.

색 태그 이름은 색마다 입력합니다. 안내: `색별 이름을 지정해 보정 방식 등 나만의 분류로 — ⇧1~5로 부여`.

## 캐시

한 번 디코딩한 썸네일은 디스크 캐시에 남아 폴더를 다시 열어도 재디코딩 없이 뜹니다.

- Windows: `%LOCALAPPDATA%\RawBlow\thumb-cache`
- macOS: OS 캐시 디렉터리 아래 RawBlow

**자동 상한** 기본은 1024MB(1GB)입니다. 0이면 무제한입니다. 상한을 넘으면 오래된 썸네일부터 지웁니다. 폴더를 열 때와 설정을 바꿀 때 정리됩니다. **캐시 비우기**로 지금 비울 수 있습니다.

## 단축키

사진 위에서 바로 누르면 됩니다. 입력창이 열려 있지 않으면 즉시 반응합니다. 앱 안에서 `?` 또는 `F1`, 툴바 **?** 로 같은 표를 봅니다.

<!-- SCREENSHOT-PLACEHOLDER: shortcuts-overlay -->

> **캡처 지시 (Windows / macOS)**
>
> - **창:** RawBlow 위에 뜬 **단축키** 오버레이. 부제 `사진 위에서 바로 누르면 됩니다 — 입력창이 없어 즉시 반응`.
> - **준비:** 폴더를 연 뒤 `?` 또는 `F1`을 누릅니다. 섹션 **이동 / 분류 / 별점·태그 / 보기 / 확대 / 파일**이 두 열로 보여야 합니다. 창을 충분히 크게 해 스크롤 없이 전체가 보이게 합니다.
> - **찍을 컨트롤:** 단축키 오버레이 전체.
> - **크롭:** 오버레이 카드만. 키캡과 한글 설명이 잘리지 않게 합니다.
> - **넣기:** 이 블록을 PNG로 바꿉니다.

## 네트워크를 쓰는 설정

앱은 계정·로그인이 없고, 아래를 쓸 때만 인터넷에 연결합니다.

1. **새 버전 자동 확인** (끌 수 있음). GitHub API만 조회합니다. 사진은 올리지 않습니다.
2. **촬영 위치 지도** (`M`). GPS가 있는 사진의 지도 타일을 OpenStreetMap에 요청합니다.
3. **AI 컬링 모델 다운로드**. GitHub Releases의 모델 파일만 받습니다. 사진은 올리지 않습니다.

자세한 항목은 저장소의 `PRIVACY.md`를 봅니다.
