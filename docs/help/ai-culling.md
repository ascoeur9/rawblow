# AI 컬링

좌측 레일 아래 **✨ AI 컬링**으로 엽니다. 사진을 이 컴퓨터 안에서 분석해 좋음과 탈락을 자동으로 매깁니다. 결과는 라벨·별점·컬러 태그 중 **지정한 축 하나**에만 들어가므로, 손으로 매긴 다른 축은 그대로입니다.

원본 파일은 삭제되지 않습니다. 걸러진 컷도 라벨·별점·태그 값만 바뀝니다.

> **모델이 판정하는 항목은 테스트 중입니다.** 얼굴 검출, AI 선명도, 객체 포함, 미적(구도) AI 같은 판정에는 오류가 있을 수 있습니다. 결과만 보고 원본을 지우거나 전송하지 않습니다. 초점·노출·수평처럼 모델 없이 도는 기준도 임계값에 따라 과하게 탈락할 수 있습니다. 끝난 뒤 사람이 한 번 더 넘깁니다.

부제 문구: `사진을 분석해 자동 분류 — 초점·노출·수평부터 미적 AI·연사 베스트·중복 정리까지 · 전부 로컬 처리`.

## 하기 전에

1. 폴더를 연 상태여야 합니다.
2. 결과를 받을 축을 정합니다. 손으로 이미 쓴 축은 피합니다. 기본은 **선택**(좋음 → 선택, 탈락 → 제외)입니다.
3. 검사 칩을 하나 이상 켭니다. 꺼져 있으면 `검사 항목을 하나 이상 켜세요.`가 뜨고 **컬링 시작**이 비활성입니다.

분석은 백그라운드로 돌아가며 도중에 취소할 수 있습니다. 진행 중에는 결과 축의 수동 편집이 잠기고, 전송·정리도 막힙니다. 폴더를 바꾸면 진행 중인 컬링이 취소됩니다.

## 기본 화면 (검사 칩)

처음 열면 **고급 옵션**은 접혀 있습니다. 기본으로 보이는 것은 검사 칩, 결과 지정, 범위, **컬링 시작**입니다.

| 칩 | 모델 | 하는 일 (칩에 커서를 올리면 같은 안내) |
|----|------|------------------------------------------|
| 초점(선명도) | 없음 | 흐린 사진(핀이 나간 컷)을 걸러냅니다 |
| 노출 | 없음 | 심하게 어둡거나 하얗게 날아간 사진을 걸러냅니다 |
| 수평 기울기 | 없음 | 수평이 기울어진 사진을 걸러냅니다 |
| 미적(구도) AI | 필요 | AI가 구도·분위기를 채점해 잘 나온 컷을 고릅니다 |

미적(구도) AI를 켜면 칩 바로 아래에 모델 상태가 나옵니다. 없으면 **미적 모델 다운로드** 버튼이 생깁니다. 모델은 사진이 아니라 **GitHub Releases**(`models-v1`)에서만 내려받습니다.

> **캡처 지시 (Windows / macOS)**
>
> - **창:** RawBlow 위에 뜬 **AI 컬링** 모달.
> - **준비:** 좌측 레일 **✨ AI 컬링**을 누릅니다. **고급 옵션**은 접힌 상태(`▸ 고급 옵션`). **검사**에 초점(선명도)·노출·수평 기울기·미적(구도) AI 칩이 보입니다. 초점·노출·수평은 켠 상태, 미적은 끈 상태로 찍으면 모델 다운로드 버튼 없이 기본 흐름이 보입니다. 아래 **결과 지정**(선택 / 별점 / 색 태그), **범위**(전체 / 현재 필터), 푸터 **분석 대상**, **컬링 시작**, **취소**.
> - **찍을 컨트롤:** 모달 전체. 헤더 부제 `전부 로컬 처리`가 보이게.
> - **크롭:** 모달 카드만. 뒤 사진 그리드는 자릅니다.
> - **넣기:** 이 블록을 PNG로 바꿉니다.

## 결과 지정 (배정 축)

한 축만 고릅니다.

| 축 | 좋음 | 탈락 |
|----|------|------|
| 선택 | 선택 (Pick) | 제외 (Reject) |
| 별점 | 지정한 별(기본 5★) | 지정한 별(기본 1★) |
| 색 태그 | 지정한 색(기본 청록) | 지정한 색(기본 주황) |

화면 안내(선택 축): `좋음 → 선택(Pick) · 탈락 → 제외(Reject)`.

컬링이 돌아가는 동안 그 축은 잠깁니다.

- 선택 축: `AI 컬링 중 — 선택(라벨)이 잠겨 있습니다`
- 별점 축: `AI 컬링 중 — 별점이 잠겨 있습니다`
- 색 태그 축: `AI 컬링 중 — 색 태그가 잠겨 있습니다`

## 범위

- **전체 N 항목:** 폴더의 모든 사진
- **현재 필터 M 항목:** 지금 보기 필터를 통과한 사진만

푸터 **분석 대상** 장수가 이 범위입니다. 대략 속도 문구는 모드에 따라 `~200장/초+ (모델 불필요·가장 빠름)`, `~90장/초 내외 (CPU)`, `~100장/초 내외 (GPU)`입니다. 아래 작은 글씨: `실제 속도는 디코딩·디스크 속도에 따라 다릅니다`.

## 고급 옵션

접기 줄: **▸/▾ 고급 옵션**, 오른쪽 작은 글씨 `메타 필터·연사·중복·AI 축·검출`.

접혀 있어도 이미 켜 둔 고급 항목은 계속 적용됩니다. 그때 경고 **고급 옵션이 적용 중입니다**가 노란 글씨로 붙습니다.

> - **크롭:** 모달 카드만. 스크롤바는 잘려도 됩니다. 두 장이면 `고급-메타` / `고급-검출`로 붙입니다.
> - **넣기:** 이 블록을 PNG로 바꿉니다.

### 옵션 (켠 검사의 세부값)

초점·노출·수평·미적을 켠 경우에만 해당 줄이 생깁니다.

| 항목 | 내용 |
|------|------|
| 흐림 임계 | 높일수록 더 엄격하게 흐림으로 판정합니다 (슬라이더) |
| AF 측거점만 | 초점을 사진 전체가 아니라 카메라가 맞춘 AF 지점에서만 봅니다. 기본 켜짐 |
| 노출 하한 | 이보다 어두운 컷을 탈락 |
| 허용 기울기 | 도(°) |
| ⚡ GPU 고속 모드 | 미적 채점을 GPU로. Windows는 WebGPU, macOS는 CoreML. 실패하면 CPU로 떨어집니다 |
| 백본 | GPU를 끈 미적 모드에서 모델 크기 선택. 클수록 정확하지만 느립니다 |
| 선택 기준 | **상위 N장**(최고 점수) 또는 **임계값**(미적 점수 하한). 임계값 모드의 슬라이더는 `P(good) ≥` |

### 메타 필터 (모델 없음)

EXIF만 봅니다. 카메라·렌즈 목록은 폴더를 읽으며 채워지고, 그동안 `메타 수집 중… (잠시 후 목록이 채워집니다)`가 나옵니다.

| 항목 | 내용 |
|------|------|
| 방향 | 전체 / 세로 / 가로 |
| ISO 상한 | 초과 컷 제외 |
| 초점거리 | mm 범위 |
| 조리개 ≤ | f 값 상한 |
| 셔터 하한 | `1/N`초. 더 느린 컷을 손떨림 후보로 제외 |
| 카메라 · 렌즈 | 이 폴더에 있는 이름. **(전체)** 는 제한 없음 |

### 중복 정리 (모델 없음)

| 칩 | 내용 |
|----|------|
| 연사 베스트-N | 짧은 간격으로 찍힌 연사를 묶어 그룹당 베스트 N장만 남깁니다. **간격 ≤** 초, **그룹당** 장 |
| 시각적 중복 묶기 | 거의 같은 장면을 묶어 베스트만 남깁니다. **차이 허용 ≤** (값이 클수록 느슨), **클러스터당** 장 |

그룹 내 베스트는 `그룹 내 베스트는 점수(미적>선명도) 기준 선택`입니다. 원본을 지우지 않고 탈락 쪽 축 값만 바꿉니다.

### AI 축 · 검출 (모델 필요, 테스트 중)

| 항목 | 모델 | 내용 |
|------|------|------|
| 장르 픽 | YuNet (얼굴, 약 0.2MB) | 인물(얼굴 있음) / 풍경(얼굴 없음) |
| AI 선명도 | CLIP 다축 (약 89MB) | `P(sharp) ≥` |
| 얼굴 있는 컷만 | YuNet | 얼굴이 검출된 컷만 좋음 |
| 객체 포함 | YOLOv10n (약 9MB) | 영문 클래스명. 예: `person`, `dog` |

객체 이름을 모르면 `객체 이름(영문) — 예: person, dog`가 노란 안내로 남고 시작 버튼이 비활성입니다.

장르 픽 안내: `장르 픽: 얼굴 검출(YuNet) 기반`.

## 모델 다운로드

모델은 앱에 내장되어 있지 않습니다. 해당 검사를 처음 켤 때 GitHub Releases의 `models-v1`에서 `.onnx`를 받고 sha256으로 검증합니다.

- 주소 형태: `https://github.com/ascoeur9/rawblow/releases/download/models-v1/…`
- 사진은 업로드하지 않습니다. 모델 파일만 받습니다.
- 저장 위치: OS 설정 폴더 아래 `models/` (Windows `%APPDATA%\RawBlow\models`, macOS `~/Library/Application Support/RawBlow/models`)

다운로드 모달 제목은 **모델 다운로드**입니다. 진행률(MB, %), 속도(MB/s), **취소**(`Esc`)가 있습니다. 끝나면 **모델 다운로드 완료** 토스트 후 컬링 창이 다시 열립니다. 취소하면 **모델 다운로드를 취소했습니다**. 해시가 다르면 `sha256 불일치 — 다시 시도해주세요`입니다.

이 빌드에 다운로드 기능이 없으면 `이 빌드에는 모델 다운로드가 포함되지 않았습니다`가 나옵니다. Store/공식 릴리즈 빌드에는 버튼이 있습니다.

<!-- SCREENSHOT-PLACEHOLDER: model-download -->

> **캡처 지시 (Windows / macOS)**
>
> - **창:** **모델 다운로드** 진행 모달. 뒤는 어둡습니다.
> - **준비:** AI 컬링에서 **미적(구도) AI**를 켠 뒤, 모델이 없는 상태에서 **미적 모델 다운로드**를 누릅니다. 진행 막대와 `12.3 / 89.0 MB · 14% · 3.1 MB/s` 같은 숫자가 움직이는 순간. 네트워크가 연결된 상태. 모델이 이미 있으면 `models` 폴더의 해당 `.onnx`를 잠시 옮겨 없는 상태로 만든 뒤 찍습니다.
> - **찍을 컨트롤:** 모달 전체. 제목 **모델 다운로드**, 모델 이름(예: 백본 이름 또는 `YuNet (얼굴)`), 진행 막대, MB/%, **취소**, `Esc`.
> - **크롭:** 모달 카드만.
> - **넣기:** 이 블록을 PNG로 바꿉니다.

모델 파일은 GitHub 릴리즈 자산이지 사용자 사진이 아닙니다. 사진 폴더에서 모델을 찾지 않습니다.

## 실행 · 취소 · 끝난 뒤

1. 검사와 결과 축을 확인하고 **컬링 시작**을 누릅니다.
2. 좌측 레일 버튼이 **✨ 분석 N%** 로 바뀝니다. 메인 창에서 사진을 넘길 수 있습니다. 잠긴 축만 못 바꿉니다.
3. 멈추려면 분석 버튼을 다시 누르거나 취소를 택합니다. 확인: **분석을 멈추시겠어요?** / **컬링 취소** / **계속 진행**.
4. 끝나면 토스트 `AI 컬링 완료 · 좋음 N · 탈락 M` (캐시에서 재사용한 장은 ` · 캐시 N장`).
5. 좌측 필터로 선택/제외(또는 별·색)를 걸러 사람이 다시 봅니다. 필요하면 `Ctrl+Z` / `⌘Z`로 되돌립니다.

폴더를 바꾸려 하면 `폴더를 바꾸면 진행 중인 AI 컬링이 취소됩니다.` 확인 후 **폴더 바꾸기** 또는 **계속 컬링**입니다.

같은 파일·같은 검사 신호로 다시 돌리면 캐시를 씁니다. 임계값만 바꾸면 디코딩을 건너뛰고 바로 재판정하는 경우가 많습니다. 검사 종류나 모델을 바꾸면 다시 계산합니다.

> **캡처 지시 (Windows / macOS)**
>
> - **창:** RawBlow 메인 창. 컬링이 진행 중인 상태.
> - **준비:** 모델 없는 검사(초점·노출)만 켜고 장수가 많은 폴더에서 **컬링 시작**을 누릅니다. 좌측 레일 하단 버튼이 `✨ 분석 37%`처럼 퍼센트를 보여야 합니다. 가능하면 선택 축이 잠긴 채 `Q`를 눌렀을 때 토스트 `AI 컬링 중 — 선택(라벨)이 잠겨 있습니다`가 떠 있는 순간을 함께 담습니다.
> - **찍을 컨트롤:** 좌측 레일 하단 **분석 N%** 버튼 + (있으면) 하단 토스트.
> - **크롭:** 레일 하단과 토스트. 사진 얼굴이 크면 레일만 남깁니다.
> - **넣기:** 이 블록을 PNG로 바꿉니다.

## 권하지 않는 것

- 모델 판정(미적·얼굴·객체·AI 선명도) 결과를 전송·삭제 전에 검토 없이 쓰지 않습니다. 테스트 중입니다.
- 결과 축을 손으로 쓰던 축과 같게 두면 그 값이 덮입니다. 별점으로 이미 고르고 있다면 컬링은 색 태그 축에 두는 식이 안전합니다.
- 컬링은 원본을 지우지 않습니다. 파일을 없애려면 끝난 뒤 사람이 **전송**의 **이동**을 쓰거나, OS에서 직접 지웁니다.
