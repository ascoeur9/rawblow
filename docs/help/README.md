# RawBlow 사용 도움말

RawBlow는 RAW와 JPEG를 빠르게 넘기며 **선택 · 보류 · 제외**로 고르는 데스크톱 셀렉 도구입니다. Windows와 macOS(Apple Silicon)로 배포하며, 분류 결과는 원본 파일을 건드리지 않고 폴더 안 사이드카에만 기록합니다.

평소에는 RAW 안에 들어 있는 임베디드 프리뷰를 띄워 넘기고, 초점과 디테일을 볼 때만 **ORIG**로 원본 해상도를 불러옵니다.

## 첫 셀렉

1. [설치](install.md) 뒤 RawBlow를 실행합니다.
2. 좌상단 **폴더 열기**(`Ctrl+O` / `⌘O`)로 사진 폴더를 열거나, 창에 폴더를 끌어다 놓습니다.
3. `←` `→`로 넘기며 `Q`(선택) `W`(보류) `E`(제외)를 누릅니다.
4. 좌측 레일에서 보고 싶은 조합만 남긴 뒤 `Enter`로 **전송** 창을 열어 고른 파일만 복사하거나 옮깁니다.

라벨을 매기면 기본적으로 다음 장으로 넘어갑니다. 설정에서 **라벨링 후 자동 전진**을 끌 수 있습니다.

> **캡처 지시 (Windows / macOS)**
>
> - **창:** RawBlow 메인 창. 제목 표시줄에 RawBlow가 보입니다.
> - **준비:** 사진이 여러 장 있는 폴더를 연 뒤, 툴바에서 `Single (T)`가 켜진 상태. 창 너비는 좌측 레일·중앙 사진·하단 필름스트립이 한눈에 들어오게 잡습니다. 한국어 UI(설정 → 언어 → 한국어, 또는 OS가 한국어).
> - **찍을 컨트롤:** 창 전체. 한 프레임에 들어가야 하는 것: 상단 툴바(`폴더 열기`, `Single (T)`, `Grid (T)`, `ORIG (D)`, `전송`), 좌측 레일(분류 · 별점 · 색 · 보기 필터), 중앙 사진, 하단 필름스트립, 맨 아래 상태바.
> - **크롭:** 창 테두리만 남깁니다. 바탕화면, 작업 표시줄(Windows), Dock·메뉴 막대(macOS), 다른 앱 창은 잘라 냅니다.
> - **넣기:** 이 블록을 PNG로 바꿉니다. 도움말은 이미지 파일 없이도 읽힙니다.
