# 폴더를 열고 고르기

셀렉의 기본은 폴더를 연 뒤 `Q` `W` `E`로 라벨을 매기는 것입니다. 별점과 컬러 태그는 라벨과 다른 축이라 함께 붙일 수 있습니다. 원본 파일은 이동·삭제되지 않습니다.

## 폴더 열기

다음 중 편한 것을 씁니다.

- 좌상단 **폴더 열기** 버튼 (`Ctrl+O` / `⌘O`)
- RawBlow 창에 폴더를 끌어다 놓기

하위 폴더까지 스캔하려면 설정에서 **하위 폴더 포함 스캔**을 켭니다. 기본값은 꺼져 있습니다.

폴더를 다시 열면 마지막으로 보던 사진부터 시작합니다. 기억하는 것은 배열 순번이 아니라 파일 경로이므로, 파일을 더하거나 지워도, 정렬을 바꿔도 같은 사진을 집습니다.

<!-- SCREENSHOT-PLACEHOLDER: toolbar-open-folder -->

> **캡처 지시 (Windows / macOS)**
>
> - **창:** RawBlow 메인 창.
> - **준비:** 앱을 실행한 상태. 폴더를 아직 안 열었거나 연 직후 모두 가능. 툴바 왼쪽의 **폴더 열기 (Ctrl+O)** 또는 **폴더 열기 (⌘O)** 가 보여야 합니다.
> - **찍을 컨트롤:** 상단 툴바 왼쪽. 로고, **폴더 열기** 버튼, `Single (T)` / `Grid (T)`가 한 줄에 들어오게.
> - **크롭:** 툴바 높이만 남기고 아래 사진 영역은 자릅니다. 창 오른쪽 끝의 **전송**까지 넣어도 됩니다. 작업 표시줄/Dock은 넣지 않습니다.
> - **넣기:** 이 블록을 PNG로 바꿉니다.

## 화면에서 쓰는 이름

좌측 레일과 필터에 나오는 라벨 이름은 아래와 같습니다.

| 키 | 화면 이름 | 단축키 도움말(`?`)에서의 이름 |
|----|-----------|-------------------------------|
| `Q` | 선택 | 채택 |
| `W` | 보류 | 보류 |
| `E` | 제외 | 제외 |
| `R` | 미선택 | 해제 |

같은 키를 다시 누르면 라벨이 풀립니다(토글). `R`은 현재 사진의 라벨을 미선택으로 되돌립니다.

## 라벨 (`Q` `W` `E` `R`)

1. 사진을 엽니다.
2. `Q` 선택, `W` 보류, `E` 제외를 누릅니다.
3. 잘못 눌렀으면 같은 키를 다시 누르거나 `R`로 미선택에 둡니다.

**라벨링 후 자동 전진**이 켜져 있으면(기본값) 라벨을 매긴 뒤 다음 장으로 넘어갑니다. 설정에서 끕니다.

좌측 레일 **분류** 구역에도 같은 네 항목이 장수와 함께 나옵니다. 현재 사진의 라벨이 강조됩니다.

<!-- SCREENSHOT-PLACEHOLDER: left-rail-classify -->

> **캡처 지시 (Windows / macOS)**
>
> - **창:** RawBlow 메인 창.
> - **준비:** 폴더를 연 뒤 몇 장에 `Q` `W` `E`를 매겨, 분류 구역에 장수가 0이 아니게 합니다. 별점(`1`~`5`)과 컬러 태그(`⇧1`~`⇧5`)도 한두 장에 붙여 두면 레일 전체가 채워집니다.
> - **찍을 컨트롤:** 좌측 레일 전체. 위에서 아래로 **분류**, **별점**, **색**, **진행**, **보기 필터**, **별점 필터**, **색 필터**, 하단 **정리** / **AI 컬링**이 보이게.
> - **크롭:** 레일 너비만 남깁니다. 중앙 사진과 툴바는 잘라도 됩니다. 레일 오른쪽 경계선은 남겨 패널임을 알 수 있게 합니다.
> - **넣기:** 이 블록을 PNG로 바꿉니다.

## 별점 (`1`~`5`, 백틱)

숫자 `1`~`5`로 별점을 매깁니다. `` ` ``(백틱)으로 해제합니다. 라벨과 독립이라 `Q`로 선택한 사진에도 별점을 붙일 수 있습니다.

## 컬러 태그 (`⇧1`~`⇧5`)

`Shift+1`~`Shift+5`로 색을 붙이고 `Shift+0`으로 뗍니다. 한 사진에 색은 하나입니다.

| 키 | 기본 이름 |
|----|-----------|
| `⇧1` | 주황 |
| `⇧2` | 분홍 |
| `⇧3` | 청록 |
| `⇧4` | 파랑 |
| `⇧5` | 보라 |

설정 **색 태그 이름**에서 색마다 이름을 바꾸면(보정 방식 등) 필터·전송·파일명에 그 이름이 따라갑니다.

## 그리드에서 여러 장 한꺼번에

`T`로 그리드로 바꾼 뒤 고릅니다.

- `Ctrl`(`⌘`)+클릭: 한 장씩 선택에 넣거나 뺌
- 한 장을 클릭한 뒤 `Shift`+클릭: 그 사이 범위를 선택
- 고른 상태에서 `Q` `W` `E` `R` 또는 별점을 누르면 한꺼번에 적용됩니다

그리드에서 썸네일을 더블클릭하면 그 사진의 단일뷰로 들어갑니다.

<!-- SCREENSHOT-PLACEHOLDER: main-grid-multiselect -->

> **캡처 지시 (Windows / macOS)**
>
> - **창:** RawBlow 메인 창. 툴바 `Grid (T)`가 켜진 상태.
> - **준비:** 그리드에서 `Ctrl`/`⌘`+클릭 또는 `Shift`+클릭으로 여러 썸네일이 선택된 상태. 선택된 셀에 선택 표시(테두리·하이라이트)가 보여야 합니다. 일부 셀에는 선택 라벨·별점·색 배지가 보이게 미리 분류해 둡니다.
> - **찍을 컨트롤:** 중앙 그리드와 상단 툴바의 `Grid (T)` · **일괄 (B)** 버튼. 좌측 레일은 일부 들어와도 됩니다.
> - **크롭:** 창 전체에서 그리드가 주가 되게 자릅니다. 빈 여백·다른 앱은 넣지 않습니다. 파일명에 개인 정보가 있으면 아래쪽 몇 행만 남기고 잘라도 됩니다.
> - **넣기:** 이 블록을 PNG로 바꿉니다.

## 일괄 분류 (그리드, `B`)

그리드에서만 됩니다. `B` 또는 툴바 **일괄**을 누릅니다.

1. 파일명 또는 그 일부를 붙여 넣습니다. 줄바꿈·쉼표·탭으로 구분합니다.
2. **검색**을 누릅니다.
3. 매칭된 목록을 확인한 뒤 **적용할 라벨**(선택 / 보류 / 제외 / 미선택)을 고르고 **적용**을 누릅니다.

**정확히 일치**를 켜면 파일명 전체와만 맞춥니다.

<!-- SCREENSHOT-PLACEHOLDER: bulk-dialog -->

> **캡처 지시 (Windows / macOS)**
>
> - **창:** RawBlow 위에 뜬 **일괄 분류 변경** 모달. 뒤 메인 창은 어둡게 가려집니다.
> - **준비:** 그리드 모드에서 `B`를 누릅니다. 입력칸에 파일명 일부를 넣고 **검색**까지 눌러 매칭 건수가 보이게 합니다. 제목 아래 부제 `파일명·일부 → 매칭 → 라벨 적용`이 보여야 합니다.
> - **찍을 컨트롤:** 모달 전체. 입력칸, **정확히 일치**, **검색**, 매칭 목록, **적용할 라벨** 칩, **적용**, **닫기 (Esc)**.
> - **크롭:** 모달 카드만 남깁니다. 뒤 화면의 사진·파일명은 어둡게 보이더라도 잘리지 않은 개인 정보가 있으면 모달 바깥을 완전히 자릅니다.
> - **넣기:** 이 블록을 PNG로 바꿉니다.

## 되돌리기

- 되돌리기: `Ctrl+Z` / `⌘Z`
- 다시 실행: `Ctrl+Shift+Z` / `⌘⇧Z`, 또는 `Ctrl+Y` / `⌘Y`

라벨·별점·컬러 태그 변경이 대상입니다. 되돌릴 작업이 없으면 토스트에 **되돌릴 작업이 없습니다**가 뜹니다.

## 사이드카 · 비파괴 저장

라벨·별점·컬러 태그는 사진 파일이 아니라 폴더 안 `.rawblow/`에 비파괴로 저장됩니다. 원본 RAW/JPEG는 이동·삭제·이름 변경되지 않습니다.

| 파일 | 역할 |
|------|------|
| `.rawblow/session.json` | 앱이 읽고 쓰는 분류 데이터 |
| `.rawblow/session.txt` | 사람이 읽는 텍스트 사본 |
| `.rawblow/session.json.bak` | 직전 정상 저장본. `session.json`이 깨지면 여기서 복구를 시도합니다 |

폴더를 다시 열면 분류가 복원됩니다.

쓰기 권한이나 용량이 부족하면 상태바에 **저장 실패**가 뜨고, 토스트에 폴더 권한·용량을 확인하라는 안내가 나옵니다.

앱 설정(언어, 단축키 기본값, 캐시 한도 등)은 사진 폴더가 아니라 OS 설정 폴더에 있습니다.

- Windows: `%APPDATA%\RawBlow`
- macOS: `~/Library/Application Support/RawBlow`

## 정렬

기본은 **촬영시간순**입니다. 여러 카메라를 섞으면 파일명이 촬영 순서와 어긋날 수 있어 시간순이 기본입니다. 설정 **정렬 기준**에서 **파일명순**으로 바꿉니다.
