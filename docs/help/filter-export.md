# 필터 · 전송 · 정리

좌측 레일에서 보고 싶은 사진만 남긴 뒤, **전송**으로 고른 파일을 복사하거나 옮깁니다. **정리**는 폴더 안 사진을 촬영일·카메라 등 기준 하위폴더로 나누는 별개 기능입니다.

## 보기 필터

라벨 필터, 별점 필터, 색 필터는 서로 독립이며 **AND**로 겹칩니다. 예: 선택 AND 정확히 ★3 AND 청록.

- **보기 필터:** 전체 / 선택 / 보류 / 제외 / 미선택. `F`로 라벨 필터만 순환합니다.
- **별점 필터:** **전체**, 또는 정확히 N점.
- **색 필터:** **전체**, 또는 특정 색.

필터에 하나도 안 남으면 **필터와 일치하는 사진이 없습니다**와 **필터 초기화**가 나옵니다.

전송의 대상 고르기(합집합)와 다릅니다. 보기 필터는 화면에 무엇을 보여줄지이고, 전송은 어떤 라벨·별점·태그를 내보낼지입니다.

<!-- SCREENSHOT-PLACEHOLDER: left-rail-filters -->

> **캡처 지시 (Windows / macOS)**
>
> - **창:** RawBlow 메인 창.
> - **준비:** 분류·별점·색이 섞인 폴더. 보기 필터에서 **선택**만 켜고, 별점 필터에서 한 점수를, 색 필터에서 한 색을 켜 AND가 보이게 합니다. 중앙에는 필터를 통과한 사진만 남습니다.
> - **찍을 컨트롤:** 좌측 레일의 **보기 필터**, **별점 필터**, **색 필터** 세 구역. 선택된 칩이 강조된 상태가 보여야 합니다.
> - **크롭:** 레일 중 필터 세 구역만. 위쪽 분류/별점 부여 구역은 잘라도 됩니다. 칩 글자가 잘리지 않게 좌우 여백을 남깁니다.
> - **넣기:** 이 블록을 PNG로 바꿉니다.

## 점프 (`G`)

툴바 **점프 (G)** 또는 `G`.

- **순번:** 우상단 `현재 / 전체`와 같은 1부터 시작하는 번호
- **파일명:** 파일명 일부 한 개. 여러 건이면 첫 항목으로 이동하고 **N 건 매칭 — 첫 항목으로** 토스트가 뜹니다

<!-- SCREENSHOT-PLACEHOLDER: jump-dialog -->

> **캡처 지시 (Windows / macOS)**
>
> - **창:** RawBlow 위에 뜬 **점프** 모달. 부제는 `한 곳으로 이동 — 순번 또는 파일명 일부`.
> - **준비:** 폴더를 연 뒤 `G`를 누릅니다. **순번** 탭이 선택된 상태에서 힌트 `1 ~ N 사이 번호`가 보이게 합니다.
> - **찍을 컨트롤:** 모달 전체. 순번/파일명 전환, 입력칸, **점프**, **닫기 (Esc)**.
> - **크롭:** 모달 카드만. 뒤 메인 창은 자릅니다.
> - **넣기:** 이 블록을 PNG로 바꿉니다.

## 전송 (`Enter`, `Ctrl+E` / `⌘E`)

툴바 오른쪽 **전송** 또는 `Enter`. 제목은 **파일 전송**, 부제는 `선택한 라벨·별점의 파일을 복사/이동 · RAW 페어 처리`입니다.

AI 컬링이 진행 중이면 열리지 않고 **AI 컬링이 끝난 뒤 전송할 수 있습니다**가 뜹니다.

마지막에 쓴 옵션은 다음에 창을 열 때 복원됩니다. 대상 폴더만 현재 폴더 기준으로 다시 제안되며, 기본 제안 이름은 `{현재폴더}_selected`입니다.

### 범위

- **전체:** 폴더의 모든 항목 중에서 아래 라벨·별점·태그를 고릅니다.
- **현재 필터:** 지금 보기 필터를 통과한 항목만 대상으로 칩 장수를 셉니다.

### 무엇을 보낼지 (합집합)

**원본 라벨**, **별점 기준**, **컬러 태그 기준**에서 고른 조건은 OR입니다. 화면 안내: `라벨 또는 별점 중 하나라도 해당하면 전송됩니다(합집합).`

- **라벨별 하위폴더로 분기 (`/pick`, `/hold` …)**
- **태그별 하위폴더로 분기 (`@teal` …)**

둘 다 끌 수 있습니다.

### 동작 · 동반 파일 · 충돌

| 구역 | 선택 |
|------|------|
| 동작 | **복사** (원본 유지) / **이동** (원본 이동) |
| 동반 파일 | **RAW+이미지** (페어 함께) / **RAW만** / **이미지만** (JPG만) |
| 이름 충돌 시 | **자동 일련번호** (`_001` 접미) / **건너뛰기** (기존 유지) |

**이동**을 고르면 시작 전에 확인이 뜹니다. `원본 N개를 이동합니다 — 원래 폴더에서 제거됩니다.` 확인 버튼은 **이동 시작**입니다. 옮겨진 항목은 목록에서 빠지고, 현재 폴더를 다시 스캔합니다.

진행률과 **취소**가 있어 큰 폴더나 느린 드라이브에서도 멈춘 것처럼 보이지 않습니다.

<!-- SCREENSHOT-PLACEHOLDER: transfer-dialog -->

> **캡처 지시 (Windows / macOS)**
>
> - **창:** RawBlow 위에 뜬 **파일 전송** 모달(너비 넓은 카드). 뒤 화면은 어둡습니다.
> - **준비:** 선택·별점·태그가 있는 폴더에서 `Enter`를 누릅니다. **범위**, **원본 라벨**, **별점 기준**, **컬러 태그 기준**, **동작**, **동반 파일**, **대상 폴더**, **이름 충돌 시**, **리네임**이 스크롤 안에 있습니다. 가능하면 라벨 칩을 하나 이상 켜 하단 **전송 대상** 장수가 0이 아니게 합니다. 대상 폴더 칸에 경로가 들어 있는 상태.
> - **찍을 컨트롤:** 모달 전체. 헤더(제목·부제·닫기 X), 본문 상단(범위·라벨 칩), 하단 푸터(**전송 대상** 장수, RAW/이미지 수, **전송 시작**, **취소**, `Enter`/`Esc` 키캡).
> - **크롭:** 모달 카드만. 화면이 작아 본문이 스크롤되면, 한 장은 헤더+범위+라벨, 한 장은 리네임+푸터가 보이게 두 장 찍습니다. 사용자 홈 경로가 길면 대상 폴더 칸이 잘리지 않게 창을 넓힙니다.
> - **넣기:** 이 블록을 PNG로 바꿉니다.

> **캡처 지시 (Windows / macOS)**
>
> - **창:** 전송 모달 위에 한 겹 더 뜬 이동 확인 오버레이.
> - **준비:** 전송에서 동작을 **이동**으로 두고 **전송 시작**을 누른 직후. 문구 `원본 N개를 이동합니다 — 원래 폴더에서 제거됩니다.`와 버튼 **이동 시작** / **돌아가기**가 보여야 합니다.
> - **찍을 컨트롤:** 확인 카드 전체.
> - **크롭:** 확인 카드만. 뒤 전송 모달은 어두워도 잘라도 됩니다.
> - **넣기:** 이 블록을 PNG로 바꿉니다.

### 전송 시 이름 변경

**리네임**에서 고릅니다.

| 모드 | 결과 |
|------|------|
| 원본 유지 | 파일명 그대로 |
| 순번 (1,2,3) | `{seq:03}` 형식. 001, 002, … |
| 별점등급 (A1,B1…) | `{gradeseq}`. 별점 등급별로 묶은 순번 |
| 직접 입력 | 템플릿 + **선택순** 또는 **등급순** |

직접 입력 자리 표시자:

`{seq}` `{seq:03}` `{grade}` `{gradeseq}` `{stars}` `{label}` `{tag}` `{orig}`

`{seq:03}`처럼 0 패딩을 붙일 수 있습니다. 미리보기가 실시간으로 나오며, RAW+JPEG 페어는 같은 이름을 받습니다.

대상이 없으면 `대상 없음 — 위에서 라벨·별점·태그를 선택하세요.`가 나옵니다.

### 전송이 끝나면

결과 창 제목은 **전송 완료**입니다. 성공·리네임·실패 수가 나오고, 동명 파일이 있어 건너뛴 경우 **건너뜀 N — 동명 파일 존재**, 이동 후 원본 삭제에 실패한 경우 **원본 삭제 실패 N — 원본 파일이 남아 있습니다**가 붙습니다. **대상 폴더 열기**로 결과 위치를 탐색기/Finder에서 엽니다.

## 폴더 정리

좌측 레일 아래 **정리**. 전송과 별개입니다. 제목은 **폴더 자동 분류**, 부제는 `폴더 안 사진을 기준별 하위폴더로 정리 · 셀렉 전송과 별개`입니다.

AI 컬링 중에는 **AI 컬링이 끝난 뒤 정리할 수 있습니다**.

| 기준 | 동작 |
|------|------|
| 촬영일 | EXIF 날짜. 없으면 `unknown-date` |
| 카메라 | EXIF 카메라. 없으면 `unknown-camera` |
| 렌즈 | EXIF 렌즈. 없으면 `unknown-lens` |
| 초점거리 | 1mm 단위(35mm). 없으면 `unknown-focal` |
| 확장자 | 파일 확장자. 없으면 `unknown-ext` |

촬영일·카메라·렌즈·초점거리는 실행하며 EXIF를 읽습니다. RAW+JPEG 페어는 같은 폴더에 유지됩니다.

기본 대상 폴더는 지금 연 폴더입니다(그 안에 하위폴더 생성). **복사** 또는 **이동**을 고를 수 있고, 정리의 기본 동작은 이동입니다. 이동이면 전송과 같이 확인을 한 번 더 받습니다.

정리가 끝나면 생성된 하위폴더를 포함해 다시 열 수 있습니다.

> **캡처 지시 (Windows / macOS)**
>
> - **창:** RawBlow 위에 뜬 **폴더 자동 분류** 모달.
> - **준비:** 좌측 레일 **정리**를 누릅니다. **기준**에서 촬영일/카메라/렌즈/초점거리/확장자 칩, **동작** 복사/이동, **대상 폴더**, 안내 문구 `대상 폴더 안에 기준별 하위폴더가 생성됩니다.`가 보이게 스크롤합니다. 하단 **정리 시작**.
