# 포맷 · 한계 · 문제

지원하는 파일과 지금 앱이 하지 않는 일을 먼저 적습니다. 이 페이지에 없는 기능(다른 앱으로 보내기 등)은 출하 버전에 없습니다.

## 지원 포맷

RAW: `.ARW` `.CR2` `.CR3` `.NEF` `.ORF` `.RW2` `.RAF` `.DNG` `.PEF` `.SRW` `.RAW`

일반 이미지: `.JPG` `.JPEG` `.PNG` `.WEBP` `.HEIC` `.HEIF` `.TIF` `.TIFF`

HEIC 등 일부 포맷은 OS 디코더에 기댑니다. Windows에서 HEIC가 안 열리면 OS 확장(HEIF 미디어)이 없는 경우가 많습니다.

목록에 없는 바디도 임베디드 프리뷰로 보이는 경우가 많습니다. 회색 화면, 깨짐, 강제종료가 나면 [이슈](https://github.com/ascoeur9/rawblow/issues)나 hare.rinko@gmail.com으로 바디와 포맷을 알려 주세요.

## 알려진 한계

- 컬러 매니지먼트는 임베디드 ICC에서 sRGB까지입니다. 모니터 ICC는 조회하지 않고 sRGB로 가정합니다.
- 단축키를 다시 지정하는 화면이 없습니다.
- 원본 보기(ORIG)는 GPU 텍스처 한계(긴 변 약 8192픽셀) 안에서 표시합니다.
- AI 컬링 중 모델이 판정하는 항목은 테스트 단계입니다. 원본은 삭제하지 않습니다.
- 공식 사전 빌드는 Windows 11과 macOS Apple Silicon입니다.

## 저장이 안 될 때

상태바 **저장 실패**, 토스트 `셀렉 저장 실패: … — 폴더 쓰기 권한·용량을 확인하세요`.

확인할 것:

1. 사진 폴더에 쓰기 권한이 있는지 (읽기 전용 카드, NAS 권한)
2. 디스크 용량
3. 폴더 안 `.rawblow/session.json`을 다른 프로그램이 잠그지 않았는지

손상된 `session.json`은 `.corrupt`로 치우고, 있으면 `session.json.bak`으로 복구를 시도합니다.

폴더를 바꾸기 직전에 저장이 실패하면 `이전 폴더(…) 셀렉 저장 실패 — 최근 변경이 유실될 수 있습니다`.

## 사진이 안 보일 때

| 화면 | 대응 |
|------|------|
| 이 폴더에 표시할 사진이 없습니다 | 지원 확장자인지, **하위 폴더 포함 스캔**이 필요한지 |
| 필터와 일치하는 사진이 없습니다 | **필터 초기화** 또는 `F`로 라벨 필터를 전체로 |
| 이 파일을 열 수 없습니다 | 사진을 클릭해 재시도. 반복되면 포맷·바디를 이슈로 |
| 디코딩 중…이 길다 | ORIG가 켜져 있는지, NAS/느린 디스크인지. ORIG를 끄고 프리뷰로 넘깁니다 |
| 세로가 가로로 보인다 | 해당 바디 이슈일 수 있습니다. 파일을 첨부해 제보합니다 |

Windows에서 GitHub 설치 파일이 안 열리면 [설치](install.md)의 SmartScreen 절차를 봅니다. macOS 첫 실행은 **그래도 열기**입니다.

## 강제종료

강제종료가 나면 바탕화면에 `rawblow_crash.log`가 생깁니다. 이 파일은 로컬에만 있으며 앱이 어디에도 보내지 않습니다. 이슈나 메일에 첨부합니다.

함께 적으면 좋은 것:

- 어떤 동작 중이었는지 (예: 그리드에서 `↓`를 길게 누름)
- 카메라 바디와 파일 포맷, 대략 장수
- OS와 GPU

## 새 버전

설정 **새 버전 자동 확인**이 켜져 있으면 실행 후 유휴일 때 GitHub를 조회합니다. 새 버전이 있으면 좌측 레일에 **새로운 버전이 있습니다** 버튼이 뜹니다. 누르면 GitHub Releases로 갑니다. Store 설치본은 Store 업데이트를 따릅니다.
