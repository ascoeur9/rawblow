### 환경 제약으로 실패/제한

이 개발 환경에는 시스템 C 링커/개발 파일이 없다.

- `cc`, `gcc`, `clang` 없음
- `sudo`는 비밀번호가 필요해 패키지 설치 불가
- `cargo test`, 앱 빌드, 일부 재빌드는 Rust build script 링크 단계에서 `linker cc not found`로 실패
- `rust-lld` 직접 지정도 `libc`, `libm`, `libpthread`, `libdl` 등 개발용 linker symlink/startup object가 없어 실패

따라서 이 브랜치에서는 **컴파일/테스트 전체 검증은 완료하지 못했다**. CI 또는 Windows/macOS/Linux 빌드 PC에서 아래 명령을 다시 돌리는 것을 권장한다.

```bash
cargo fmt --all -- --check
cargo check --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
```

참고: `rustfmt` 설치 후 `cargo fmt --all -- --check`를 시도했으나, 변경하지 않은 기존 테스트 파일 등에서도 포맷 diff가 다수 나왔다. 이번 작업에서는 포맷 전용 대규모 변경이 실제 수정 내용을 흐릴 수 있어 자동 포맷 적용은 하지 않았다.
