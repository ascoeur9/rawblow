## Phase 1 — P0 (v0.5.7 후보)

### 1-1. 토스트 오버레이 렌더링 (S)

증상: `self.toast`를 설정하는 곳은 16곳인데 그리는 곳이 없음(만료 체크만 존재) → 안내·에러 전부 무음.

- `toast` 필드를 `Option<Toast>`로: `Toast { text, at, kind }`, `ToastKind::Info(3s) / Notice(6s) / Error(클릭까지 유지)`. 헬퍼 `toast_info/notice/error`.
- 세터 16곳 치환: 다운로드 실패·sha256 불일치·연결 끊김 → Error / AI 컬링 완료·결과 폐기 → Notice / 나머지 → Info.
- 렌더: `update()` 맨 끝, `egui::Area` + `Order::Foreground`, 우하단 앵커(상태바 위), `theme::BG3` 카드, 최대 폭 ~380 줄바꿈(멀티라인 존재), Error는 빨간 점 + 클릭 닫기.

### 1-2. 셀렉 저장 실패 표면화 + 종료 플러시 (S–M)

증상: 사이드카 저장 실패를 `let _ =`로 버리고 dirty를 무조건 내림 → 읽기 전용/권한/용량 문제 시 셀렉 무음 유실 + 상태바는 "saved" 거짓 표시. 종료 훅 없음(300ms 디바운스 창 유실).

- `save_error: Option<String>` + `save_fail_count` — 실패 시 dirty 유지, 300ms 재시도(3연속 실패부터 5s 백오프), 첫 실패에 Error 토스트.
- 상태바 3-상태: saved / saving… / **저장 실패**(빨강, hover에 오류 원문+경로).
- `open_folder` 전환 전 플러시 실패 → 이전 폴더명 포함 sticky Error 토스트(전환은 진행).
- `impl eframe::App`에 `fn on_exit(&mut self)`(eframe 0.29, glow 미포함 시그니처) — 사이드카 동기 저장 + `config::save`.
- 코어 테스트: 읽기 전용 디렉토리 저장 에러 전파(cfg(unix)).

### 1-3. Move 안전화 + 결과 정직성 + Enter (M)

- 전송·정리 공용 **Move 확인 오버레이**: "원본 {n}개를 이동합니다 — 원래 폴더에서 제거됩니다." [이동 시작]/[돌아가기]. (#57로 Move가 기억된 기본값이 될 수 있어 필수.)
- 결과 모달: `skipped>0`이면 건너뜀 라인, `TransferReport.remove_failed: Vec<PathBuf>` 신설(복사 성공·원본 삭제 실패 케이스) → "원본이 남아 있는 파일 {n}" 경고. 정리 완료창 제목 "정리 완료" 분리.
- Enter 실동작: 텍스트 입력 포커스 없을 때 Enter → 시작(Move면 확인 오버레이 경유). 배지와 동작 일치.
- 워커 채널이 Done 없이 끊기면(패닉) 합성 실패 리포트로 결과 모달 표시(현재는 무음 닫힘).
- 전송 대상 폴더 공백 검증을 `can_start`에 추가(정리와 일관).

- **A. i18n 마감**: `section_label` tr화 + 다이얼로그 캡션 일괄, 레일 PICK/HOLD → `Label::name(lang)`, Copy/Move 세그 번역. *결정 필요*: 툴바 모노 영문(Single/Grid/Fit…)이 디자인 의도인지.

- **D. 설정 다듬기**: Esc 닫기, 변경 즉시 저장 통일, 기본값 복원, HEX 무효 빨간 테두리, 캐시 경로 클릭 reveal, 업데이트 배너 × + 자동 확인 설정.
